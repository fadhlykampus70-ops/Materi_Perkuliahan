Logika dan Algoritma 2

Algoritma dan Pemrograman II merupakan mata kuliah lanjutan yang membahas penerapan konsep algoritma dan pemrograman secara lebih mendalam. Materi meliputi struktur kontrol, fungsi dan rekursi, pengolahan data menggunakan array dan string, operasi file, serta penerapan algoritma sorting dan searching. Selain itu, mahasiswa diperkenalkan pada analisis efisiensi dan kompleksitas algoritma.

Lihat materi webdesain-2 / Semester II

Web Desain 2

Perancangan web (web design) adalah istilah umum yang digunakan untuk mencakup bagaimana isi web konten ditampilkan, (biasanya berupa hypertext atau hypermedia) yang dikirimkan ke pengguna akhir melalui World Wide Web, dengan menggunakan sebuah browser web atau perangkat lunak berbasis web. Sebuah website dapat berupa sekumpulan teks, gambar, suara dan konten lainnya, serta dapat bersifat statis.
