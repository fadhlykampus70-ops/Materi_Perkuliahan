Perbandingan: HTML Biasa vs Bootstrap
Lihat perbedaan visual antara button HTML standar dan button Bootstrap.
Button HTML Biasa
<button>Tombol HTML</button>
Button Bootstrap
<button class="btn btn-primary">
  Tombol Bootstrap
</button>
Pertanyaan: Mana yang lebih menarik dan mudah digunakan? Bootstrap memberikan styling yang konsisten, responsif, dan profesional hanya dengan menambahkan class="btn btn-primary".

MINI SIMULASI — Toggle State

Klik tombol di bawah untuk mengubah state-nya

State saat ini: AKTIF
<!-- Active -->
<button class="btn btn-primary active">Aktif</button>

<!-- Disabled (HTML attribute) -->
<button class="btn btn-primary" disabled>Disabled</button>

<!-- Toggle via JavaScript -->
function toggleBtn() {
  const btn = document.getElementById('myBtn');
  btn.disabled = !btn.disabled;
}

7
Responsive Image
Gambar yang menyesuaikan ukuran container secara otomatis.

📐 Resize layar untuk melihat perubahan — gambar menyesuaikan lebar container secara otomatis

Cara kerja: Class .img-fluid menerapkan max-width: 100% dan height: auto, sehingga gambar tidak pernah melebihi lebar container-nya.
<!-- Gambar Responsif -->
<img
  src="landscape.jpg"
  class="img-fluid"
  alt="Gambar Landscape"
>

/* CSS yang dihasilkan Bootstrap */
.img-fluid {
  max-width: 100%;
  height: auto;
}

10
Mini Project
Terapkan semua yang telah dipelajari dalam satu card.

Instruksi Mini Project

Buat 1 card menggunakan Bootstrap yang terdiri dari:

  • Sebuah gambar (gunakan .img-fluid atau .rounded)
  • Judul card yang menarik
  • Deskripsi singkat (2–3 kalimat)
  • Minimal 1 tombol dengan style Bootstrap
  • Layout responsive menggunakan grid Bootstrap
