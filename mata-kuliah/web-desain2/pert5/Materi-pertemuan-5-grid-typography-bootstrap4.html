Section 2

📋 Recall — Pertemuan Sebelumnya

Sebelum lanjut, pastikan kamu ingat dasar-dasar Bootstrap dari pertemuan lalu.

🔷 Apa itu Bootstrap?

Framework CSS open-source dari Twitter. Menyediakan komponen siap pakai untuk membangun tampilan web yang konsisten.

📱 Mobile-First

Bootstrap dirancang untuk tampilan mobile terlebih dahulu, lalu menyesuaikan ke layar lebih besar (responsive).

🔗 Cara Menggunakan

Tambahkan link CDN Bootstrap di dalam tag <head>, lalu gunakan class Bootstrap di elemen HTML.

Layout dengan CSS manual sering kali tidak konsisten dan butuh banyak kode.

⚠️ Harus tulis CSS manual, hitung width sendiri, atur float, clear... ribet!

Bagaimana jika kita ingin membagi halaman menjadi 2 atau 3 bagian dengan cepat dan rapi?
⚠️ Masalah Umum Layout Manual
  • Harus menghitung lebar kolom secara manual (%, px)
  • Float dan clearfix yang rumit dan rawan bug
  • Tidak konsisten di berbagai browser
  • Banyak kode CSS hanya untuk mengatur posisi

Section 4

🧩 Pengenalan Grid Bootstrap

Grid adalah sistem pembagian layout yang membagi halaman menjadi 12 kolom secara otomatis.

🔢 Kenapa 12 Kolom?

Angka 12 mudah dibagi: 1, 2, 3, 4, 6, dan 12 — sehingga fleksibel untuk membuat berbagai kombinasi layout.

÷ 2 = 6+6 ÷ 3 = 4+4+4 ÷ 4 = 3+3+3+3 ÷ 6 = 2×6
📐 Konsep Utama

Tiga kelas kunci membentuk sistem grid Bootstrap:

└ col-*

Section 5

📏 Aturan Dasar Grid

Pahami tiga elemen utama yang wajib ada dalam setiap penggunaan Grid Bootstrap.

container
└── row
├── col-*
├── col-*
└── col-*
📦 .container

Membungkus seluruh grid. Memberikan margin kiri-kanan otomatis dan membatasi lebar konten.

📐 .row

Satu baris horizontal. Berisi kumpulan kolom. Gunakan satu .row untuk satu baris.

📊 .col-*

Kolom berisi konten. Angka * diisi 1–12 sesuai lebar yang diinginkan.

⭐ Penting Jumlah angka kolom dalam satu .row harus berjumlah tepat 12 (atau kurang dari 12 jika tidak ingin memenuhi baris).
⚠️ Kesalahan Umum Mahasiswa
  • Meletakkan .col langsung di dalam .container tanpa .row
  • Lupa menambahkan .row sehingga kolom tidak sejajar
  • Menjumlahkan kolom melebihi 12 dalam satu baris (misal: col-7 + col-7)
  • Menggunakan .container di dalam .container tanpa alasan

Section 7

↔️ Offset Column

Memberi jarak kosong di sebelah kiri kolom untuk menggeser posisinya.

📖 Apa itu Offset?

Offset menambahkan ruang kosong di sebelah kiri kolom. Gunakan .offset-* untuk menggeser kolom ke kanan.

Format: offset-{jumlah}
Contoh: col-4 offset-4 artinya kolom selebar 4 unit, dimulai dari tengah.

Section 8

🪆 Nesting Column

Kolom di dalam kolom — membuat layout yang lebih kompleks dengan cara yang tetap terstruktur.

📦 Bagaimana Cara Kerjanya?

Di dalam sebuah kolom, kamu bisa menambahkan .row baru dan kolom lagi di dalamnya. Angka kolom dihitung ulang dari 12 di dalam parent column.

<div class="row"> <div class="col-8"> <!-- Nested row di dalam col-8 --> <div class="row"> <div class="col-6">A</div> <div class="col-6">B</div> </div> </div> <div class="col-4">Sidebar</div> </div>

⭐ Ingat Di dalam kolom yang bersarang (nested), sistem 12 kolom dimulai ulang dari awal.

Section 9

🔀 Mengurutkan Kolom (Order)

Urutan tampilan kolom bisa diubah tanpa mengubah urutan HTML-nya.

🔧 Kelas Order

Gunakan .order-* untuk mengubah urutan visual kolom.

HTML (urutan asli):

A (HTML pertama)
B (HTML kedua)

Tampilan dengan order-2 dan order-1:

B tampil duluan
A tampil belakangan
<div class="row"> <!-- A di HTML tapi tampil ke-2 --> <div class="col-6 order-2"> Kolom A </div> <!-- B di HTML tapi tampil ke-1 --> <div class="col-6 order-1"> Kolom B </div> </div>
Kapan dipakai? Berguna saat desain mobile perlu urutan berbeda dari desain desktop.

Section 11

🖋️ Pengenalan Tipografi Bootstrap

Bootstrap menyediakan kelas-kelas siap pakai untuk mengatur tampilan teks secara konsisten dan profesional.

📝 Heading

h1 s/d h6 dengan ukuran dan bobot yang konsisten. Bisa juga gunakan .h1 dst.

📄 Body Copy

Teks paragraf biasa dengan line-height dan font-size yang nyaman dibaca.

🔷 Lead Body Copy

Paragraf pembuka yang lebih besar. Gunakan class .lead

✏️ Text Formatting

bold, italic, muted, small, mark, del, ins, abbr

↔️ Alignment

Rata kiri, tengah, kanan, justify dengan class text-left, text-center, text-right

🔤 Transform

Ubah huruf jadi uppercase, lowercase, atau capitalize dengan satu class

✏️ Text Formatting
BoldTeks tebal — sangat penting<strong> / <b>
ItalicTeks miring — penekanan<em> / <i>

SmallTeks lebih kecil 85%<small> / .small
MarkTeks disorot kuning<mark>

↔️ Text Alignment
.text-left
Teks rata kiri — ini adalah default yang paling umum digunakan.
.text-center
Teks rata tengah — cocok untuk judul, caption, atau tombol CTA.
.text-right
Teks rata kanan — cocok untuk harga, tanggal, atau label.
<p class="text-left">Rata kiri</p> <p class="text-center">Rata tengah</p> <p class="text-right">Rata kanan</p>
🔤 Text Transform
Uppercasesemua huruf besar.text-uppercase
LowercaseSEMUA HURUF KECIL.text-lowercase
Capitalizehuruf pertama tiap kata kapital.text-capitalize
<p class="text-uppercase">teks ini jadi kapital semua</p> <p class="text-lowercase">TEKS INI JADI KECIL SEMUA</p> <p class="text-capitalize">kapital tiap awal kata</p>
⚠️ Kesalahan Umum Tipografi
  • Menggunakan inline style untuk mengatur alignment padahal Bootstrap sudah punya class-nya
  • Memakai <b> untuk semua bold, padahal <strong> lebih semantik
  • Lupa bahwa .text-muted sudah mencakup warna abu-abu — tidak perlu tambah CSS manual
  • Menggunakan spasi non-breaking (&nbsp;) untuk mengatur jarak teks
