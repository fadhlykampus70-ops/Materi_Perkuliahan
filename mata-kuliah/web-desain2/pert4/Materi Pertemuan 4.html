STEP 1 — Masalah Dunia Nyata

Kenapa Kita Butuh Framework?

Bayangkan membangun sebuah rumah tanpa peralatan — hanya tangan kosong. Itulah rasanya bikin CSS dari nol terus.

  • 🕐 Lama — Nulis ulang style yang sama berulang kali di setiap project.
  • 😵 Tidak Konsisten — Tampilan beda di browser yang berbeda.
  • 📱 Sulit Responsif — Butuh banyak kode media query yang kompleks.

😩 Tanpa Framework

❌ Nulis CSS ratusan baris sendiri
❌ Setiap elemen didesain dari nol
❌ Responsif harus dikoding manual
❌ Konsistensi sulit dijaga

😎 Dengan Framework

✅ Desain siap dalam hitungan menit
✅ Komponen tinggal pakai
✅ Responsif otomatis dengan class
✅ Desain konsisten & profesional

Tanpa jQuery, RTL support, dan sistem utility yang lebih powerful.

STEP 4 — Konsep Mobile-First

Apa itu Mobile First?

Desain dimulai dari layar kecil (HP), lalu diperluas ke layar yang lebih besar.

STEP 5 — Struktur File

Isi Folder Bootstrap

Ketika kamu download Bootstrap, inilah struktur folder yang akan kamu temukan.

📁 bootstrap/
  ├── 📁 css/    ← tampilan & style
  │   ├── bootstrap.css
  │   └── bootstrap.min.css
  ├── 📁 js/     ← interaksi & animasi
  │   ├── bootstrap.js
  │   └── bootstrap.min.js
  └── 📁 fonts/ ← ikon (Glyphicons)
      └── glyphicons.*
🎨

Folder css/

Berisi semua style Bootstrap. File .min.css adalah versi terkompresi untuk produksi.

⚙️

Folder js/

Berisi JavaScript untuk komponen interaktif seperti modal, dropdown, tooltip.

🔤

Folder fonts/

Berisi file Glyphicons — ikon bawaan Bootstrap 4 berupa icon font.

STEP 6.5 — Glyphicon / Icon Font

Icon Font di Bootstrap

Ikon bukan sekadar hiasan — mereka membantu pengguna memahami fungsi lebih cepat.

🤔 Apa itu Icon Font?

Icon font adalah kumpulan ikon yang dikemas seperti huruf (font). Bisa diubah ukuran & warnanya menggunakan CSS — ringan dan tajam di semua layar.

✨ Kenapa Pakai Ikon?

Ikon membuat UI lebih intuitif, menghemat ruang teks, dan memberi kesan profesional pada tampilan website.

🔍 search
👤 user
🏠 home
📝 list
CONTOH PENGGUNAAN IKON (KONSEP)
<!-- Glyphicon di Bootstrap -->
<span class="glyphicon glyphicon-search"></span>
<span class="glyphicon glyphicon-user"></span>
<span class="glyphicon glyphicon-home"></span>

<!-- Atau menggunakan tag <i> -->
<i class="icon-search"></i>
STEP 7 — Cara Menggunakan Bootstrap

2 Cara Pakai Bootstrap

Pilih metode yang sesuai dengan situasimu — online atau offline.

🌐 CDN Disarankan untuk Belajar

Tambahkan link di HTML — tidak perlu download apapun. Butuh koneksi internet saat development.

📦 Download File

Download dan simpan di komputer. Cocok untuk project offline atau koneksi terbatas.

CONTOH PENGGUNAAN CDN
<!DOCTYPE html>
<html>
<head>
  <!-- 1. CSS Bootstrap -->
  <link rel="stylesheet"
        href="https://cdn.jsdelivr.net/npm/bootstrap@4.6.0/dist/css/bootstrap.min.css">
</head>
<body>

  <!-- Konten website kamu -->

  <!-- 2. JS Bootstrap (sebelum </body>) -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@4.6.0/dist/js/bootstrap.min.js"></script>
</body>
</html>
