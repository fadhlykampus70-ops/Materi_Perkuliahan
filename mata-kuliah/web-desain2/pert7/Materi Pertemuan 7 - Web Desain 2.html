Tabel

Penjelasan

Form Bootstrap 4

Komponen form yang terstruktur dan konsisten dengan Bootstrap

10
Basic Form
Form
▾
💡
Penjelasan

Gunakan class .form-group pada wrapper setiap field, .form-control pada input, dan .form-label pada label. Tiga class ini adalah fondasi form Bootstrap.

⚠️
Kesalahan Umum

Lupa menambahkan .form-control pada input — akibatnya input tidak mendapat styling Bootstrap dan terlihat seperti input HTML biasa tanpa perbaikan visual.

👁 Hasil
💻 Kode HTML
<form> <div class="form-group"> <label>Nama Lengkap</label> <input type="text" class="form-control" placeholder="Masukkan nama"> </div> <div class="form-group"> <label>Email</label> <input type="email" class="form-control" placeholder="contoh@email.com"> </div> <div class="form-group"> <label>Password</label> <input type="password" class="form-control"> </div> <button type="submit" class="btn btn-primary"> Daftar </button> </form>
11
Inline Form
Form
▾
💡
Penjelasan

Tambahkan class .form-inline pada tag <form>. Semua elemen form akan ditampilkan secara horizontal (sejajar). Cocok untuk form pencarian atau filter singkat.

👁 Hasil — Form Sejajar
💻 Kode HTML
<form class="form-inline"> <div class="form-group mr-2"> <label class="mr-2">Username</label> <input type="text" class="form-control"> </div> <div class="form-group mr-2"> <label class="mr-2">Password</label> <input type="password" class="form-control"> </div> <button class="btn btn-primary"> Login </button> </form>
12
Horizontal Form
Form
▾
💡
Penjelasan

Gunakan .form-horizontal dengan grid Bootstrap. Label berada di sebelah kiri, input di sebelah kanan. Cocok untuk form yang membutuhkan layout yang lebih rapi dan formal.

👁 Hasil — Label & Input Sejajar

16
Efek Fokus pada Input
Form
▾
💡
Penjelasan

Bootstrap secara otomatis menambahkan efek outline biru dan box-shadow ketika input mendapat fokus (diklik). Ini membantu aksesibilitas dan UX. Coba klik input di bawah!

👁 Klik input untuk melihat fokus!
💻 CSS Bootstrap (otomatis)
/* Bootstrap otomatis menambahkan efek fokus via CSS: */ .form-control:focus { border-color: #80bdff; box-shadow: 0 0 0 0.2rem rgba(0,123,255,.25); outline: 0; } /* Tidak perlu kode tambahan! Cukup class="form-control" */
17
Disabled & Readonly
Form
▾
💡
Penjelasan

disabled: input tidak bisa diklik sama sekali, nilainya tidak terkirim saat form submit. readonly: input bisa diklik tapi tidak bisa diubah, nilainya tetap terkirim.

✅
Perbedaan Kunci
  • disabled → tidak terkirim, cursor tidak diizinkan
  • readonly → tetap terkirim, bisa disorot/dicopy
👁 Hasil
💻 Kode HTML
<!-- Normal --> <input class="form-control" type="text"> <!-- Disabled --> <input class="form-control" type="text" disabled value="Tidak bisa diubah"> <!-- Readonly --> <input class="form-control" type="text" readonly value="Hanya bisa dibaca">
18
Validasi Form
Form ⭐ Penting
▾
💡
Penjelasan

Bootstrap menyediakan class .is-valid (hijau) dan .is-invalid (merah) pada input untuk memberikan feedback visual validasi. Tambahkan div .valid-feedback atau .invalid-feedback untuk pesan.

⚠️
Kesalahan Umum

Lupa menambahkan class was-validated pada form, sehingga feedback validasi tidak tampil meski sudah ada class .is-valid/invalid di input.

👁 Hasil
✓ Nama valid!
✗ Format email tidak valid.
💻 Kode HTML
<!-- Input Valid --> <input type="text" class="form-control is-valid" value="Fadhly Ahmad"> <div class="valid-feedback"> Nama valid! </div> <!-- Input Invalid --> <input type="email" class="form-control is-invalid" value="bukan-email"> <div class="invalid-feedback"> Format email tidak valid. </div>
19
Ukuran Input Form
Form
▾
💡
Penjelasan

Bootstrap memiliki 3 ukuran input: .form-control-sm (kecil), default (normal), dan .form-control-lg (besar). Pilih sesuai konteks tampilan aplikasi.

👁 Perbandingan Ukuran
💻 Kode HTML
<!-- Small --> <input class="form-control form-control-sm" type="text"> <!-- Normal (default) --> <input class="form-control" type="text"> <!-- Large --> <input class="form-control form-control-lg" type="text">

Latihan 1 — Tabel Mahasiswa
Latihan
▾

🎯 Soal: Buat Tabel Data Mahasiswa

Buat tabel dengan class .table .table-striped .table-hover .table-bordered

Tambahkan kolom: No, NIM, Nama, Jurusan, IPK, Status

Isi minimal 5 baris data mahasiswa

Beri warna table-success untuk IPK ≥ 3.5, table-danger untuk IPK < 2.5
