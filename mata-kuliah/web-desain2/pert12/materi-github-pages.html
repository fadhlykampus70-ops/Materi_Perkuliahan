Publish Hasil Kerjamu ke GitHub Pages

Pelajari cara mengunggah file HTML kamu ke internet secara gratis menggunakan GitHub — tanpa install apapun, cukup lewat browser.

⏱ ~15 menit 🌐 Cukup browser 💸 Gratis 📁 1 file HTML
Sebelum Mulai

Apa itu GitHub & GitHub Pages?

Dua hal berbeda yang bekerja bersama untuk membuat website kamu bisa diakses siapapun di internet.

📦

GitHub

Tempat menyimpan file kode secara online. Seperti Google Drive, tapi khusus untuk project web dan kode program.

🌐

Repository

Folder project kamu di GitHub. Setiap project punya repository sendiri untuk menyimpan semua file-nya.

🚀

GitHub Pages

Fitur GitHub yang otomatis menjadikan file HTML kamu sebagai website yang bisa diakses publik dengan URL sendiri.

🔗

URL Hasil

Setelah aktif, website kamu bisa diakses di: username.github.io/nama-repo

💡

Analogi sederhana: GitHub itu seperti flashdisk online. GitHub Pages itu fitur yang membuat isi flashdisk tersebut bisa dilihat semua orang lewat browser.

Panduan Lengkap

Langkah-langkah Publish

Ikuti 6 langkah berikut secara berurutan. Estimasi waktu: 10–15 menit untuk pertama kali.

1

Buat Akun GitHub

Buka github.com dan daftar akun baru. Gunakan email aktif kamu. Pilih username yang profesional — ini akan muncul di URL website kamu.

github.com/signup
Username
mahasiswaku123
Email address
email@student.ac.id
Password
••••••••••

ℹ️

Username akan menjadi bagian URL kamu. Contoh: username budi123 → URL: budi123.github.io/...

2

Buat Repository Baru

Setelah login, klik tombol New atau tombol + di pojok kanan atas → pilih New repository.

github.com/new
Repository name *
uts-web-design
Visibility
● Public — Pilih ini agar bisa di-publish
⚠️

Wajib pilih Public! Repository Private tidak bisa di-publish ke GitHub Pages secara gratis. Nama repository bebas, tapi hindari spasi — gunakan tanda hubung ( - ).

3

Upload File HTML

Di halaman repository yang baru dibuat, klik uploading an existing file atau Add file → Upload files.

github.com/budi123/uts-web-design/upload
📁
Drag & drop file di sini
atau klik untuk pilih file
Commit changes
Upload file UTS

✅

File yang di-upload: Cukup upload 1 file index.html dari starter file UTS kamu. Pastikan nama filenya tepat index.html.

4

Cek File Sudah Terupload

Kembali ke halaman utama repository. File kamu seharusnya sudah muncul di sana seperti ini:

github.com/budi123/uts-web-design
📂 uts-web-design
Public
📁 .github Initial commit
📄 index.html Upload file UTS
5

Aktifkan GitHub Pages

Ini langkah terpenting! Klik Settings (tab paling kanan) → scroll ke bawah → cari bagian Pages di menu kiri.

github.com/budi123/uts-web-design/settings/pages
GitHub Pages
Source
Branch: main ▾
/ (root) ▾
✅ Your site is published at
https://budi123.github.io/uts-web-design/
⏳

Tunggu 1–3 menit setelah klik Save. GitHub butuh waktu untuk memproses. Refresh halaman Settings → Pages untuk melihat URL-nya muncul.

6

Buka & Test Website Kamu

Setelah URL muncul di Settings → Pages, klik URL tersebut. Website UTS kamu sudah live dan bisa dilihat siapapun!

🎉
https://username.github.io/nama-repo/
Ganti username dengan username GitHub kamu & nama-repo dengan nama repository.
Pengumpulan UTS

Cara Mengirimkan Link ke Dosen

Setelah website berhasil di-publish, salin linknya dan kirimkan ke dosen sesuai instruksi pengumpulan.

📋

Salin URL

Pergi ke Settings → Pages. Copy link yang muncul di bagian atas (diawali https://).

✉️

Kirim via LMS / WA

Paste link tersebut ke kolom pengumpulan yang sudah diarahkan dosen. Pastikan linknya bisa dibuka.

🔍

Test Sebelum Kirim

Buka link di browser lain / incognito mode untuk memastikan website tampil dengan benar.

✅

Format link yang benar: https://username.github.io/nama-repository/
Contoh: https://budisantoso.github.io/uts-web-design/

Checklist Sebelum Kirim
  • File bernama index.html Nama file harus tepat "index.html" (huruf kecil semua)
  • Repository berstatus Public Cek di halaman repository — ada badge "Public" di sebelah nama
  • GitHub Pages sudah diaktifkan Settings → Pages → Source sudah di-set ke branch main
  • URL bisa dibuka Test buka link di browser incognito atau dari HP lain
  • Tampilan sesuai Pastikan CSS dan konten tampil normal, tidak ada yang rusak
Pertanyaan Umum

FAQ & Troubleshooting

Masalah yang paling sering terjadi dan cara mengatasinya.

URL sudah ada tapi website tidak tampil / error 404

Kemungkinan nama file bukan index.html. GitHub Pages secara default mencari file bernama index.html di root repository. Cek nama file di repository kamu — pastikan hurufnya kecil semua: index.html, bukan Index.html atau index.HTML.

Tidak menemukan menu "Pages" di Settings

Pastikan repository kamu berstatus Public. Repository Private tidak menampilkan menu GitHub Pages secara gratis. Cara mengubah: Settings → scroll ke bawah → bagian "Danger Zone" → Change repository visibility → Public.

Sudah klik Save tapi URL tidak muncul

GitHub Pages butuh waktu 1–5 menit untuk pertama kali aktif. Tunggu beberapa menit lalu refresh halaman Settings → Pages. Jika lebih dari 10 menit masih tidak muncul, coba ulangi langkah pengaktifan: pilih branch main dan folder / (root) lalu Save lagi.

Website tampil tapi CSS / gambar tidak muncul

Ini terjadi karena path file di HTML menggunakan path absolut (misalnya C:\Users\nama\Desktop\style.css). Karena kamu menggunakan 1 file HTML tunggal dengan CSS dan JS di dalamnya (inline), masalah ini tidak akan terjadi. Pastikan semua CSS dan JS sudah ada di dalam file index.html.

Sudah update file tapi website belum berubah

GitHub Pages butuh 1–3 menit untuk update setelah kamu commit file baru. Coba hard refresh browser: tekan Ctrl + Shift + R (Windows) atau Cmd + Shift + R (Mac). Bisa juga buka di browser incognito untuk menghindari cache.

Lupa password / tidak bisa login GitHub

Gunakan fitur "Forgot password" di halaman login GitHub. Link reset akan dikirim ke email yang kamu daftarkan. Pastikan cek folder spam jika email tidak masuk dalam 5 menit.
