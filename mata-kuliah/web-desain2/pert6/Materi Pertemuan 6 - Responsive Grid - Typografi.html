Section 2

📌 Recall: Grid Dasar Bootstrap

Sebelum masuk ke responsive, kita ingat kembali komponen utama Bootstrap Grid.

.container
Membungkus seluruh konten, memberikan max-width
.row
Baris horizontal yang menampung kolom-kolom
.col
Kolom di dalam row, membagi ruang secara horizontal
12 Kolom
Sistem Bootstrap menggunakan 12 unit kolom dalam 1 baris

Section 4 — Core

📏 Pengenalan Responsive Breakpoint

Bootstrap punya sistem breakpoint bawaan — ukuran layar yang menjadi titik perubahan layout.

📱
Mobile
< 576px
1 Kolom
📟
Tablet (sm/md)
576px – 992px
2 Kolom
🖥️
Desktop (lg/xl)
> 992px
3 Kolom
📊 Tabel Breakpoint Bootstrap 4
Prefix Ukuran Layar Device Contoh Class
(none) < 576px 📱 Mobile kecil col-12
sm ≥ 576px 📱 Mobile besar col-sm-6
md ≥ 768px 📟 Tablet col-md-6
lg ≥ 992px 🖥️ Desktop col-lg-4
xl ≥ 1200px 🖥️ Desktop besar col-xl-3

Section 6

🧠 Penjelasan Logika Responsive

Setiap class memiliki "titik aktif" berdasarkan lebar layar.

📱
col-12
Aktif di HP. Kolom memenuhi seluruh lebar (12 dari 12 unit). Tampil 1 kolom per baris.
12 / 12 kolom
📟
col-md-6
Aktif di Tablet (≥768px). Kolom mengambil 6 dari 12 unit. Tampil 2 kolom per baris.
6 / 12 kolom × 2
🖥️
col-lg-4
Aktif di Desktop (≥992px). Kolom mengambil 4 dari 12 unit. Tampil 3 kolom per baris.
4 / 12 kolom × 3
✅
Ingat Prinsip Mobile-First!
Bootstrap bekerja secara mobile-first. Class tanpa prefix (misal col-12) aktif dari ukuran terkecil, dan class dengan prefix mengoverride untuk layar yang lebih besar.

Section 9–10

🔤 Typography Lanjutan Bootstrap

Setelah layout, kita buat konten tampil rapi dengan class-class typography Bootstrap.

A — Text Muted & Small ▾
👁️ Hasil
text-muted

Teks utama tampil normal seperti ini.

Ini teks keterangan yang lebih redup (text-muted).

small

Teks normal untuk konten.

Ditulis oleh: Admin — 16 April 2026
💻 Kode
<p>Teks utama normal.</p> <p class="text-muted"> Teks keterangan redup. </p> <p>Teks konten utama.</p> <small class="text-muted"> Info kecil di sini. </small>
💡
Kapan digunakan?
text-muted: untuk keterangan, meta info, label sekunder. small: untuk catatan kaki, tanggal, penulis.
B — Address ▾
👁️ Hasil
address
Universitas Contoh
Jl. Pendidikan No. 1
Jakarta Selatan, 12345
Telp: (021) 123-4567
💻 Kode
<address> <strong>Universitas Contoh</strong><br> Jl. Pendidikan No. 1<br> Jakarta Selatan<br> <abbr title="Telepon">Telp:</abbr> (021) 123-4567 </address>
💡
Tag <address> secara semantik menandai informasi kontak. Bootstrap memberi styling italic dan margin otomatis.
C — Code & Pre ▾
👁️ Hasil
inline code

Gunakan class container untuk membungkus konten.

Tambahkan row di dalamnya, lalu col.

pre — blok kode
.container {
  max-width: 1140px;
  margin: 0 auto;
}
💻 Kode
<!-- Inline code --> <p>Gunakan <code>container</code></p> <!-- Blok kode --> <pre> .container { max-width: 1140px; } </pre>
D — Blockquote ▾
👁️ Hasil
blockquote

"Responsive design bukan fitur tambahan — ini adalah keharusan di era mobile."

— Ethan Marcotte, Responsive Web Design
💻 Kode
<blockquote class="blockquote"> <p>Kutipan teks...</p> <footer class="blockquote-footer"> Penulis </footer> </blockquote>
E — List (ul & ol) ▾
👁️ Hasil
Unordered List (ul)
  • Responsive Grid
  • Breakpoint sm, md, lg
  • Typography Bootstrap
Ordered List (ol)
  1. Buat container
  2. Tambahkan row
  3. Isi dengan col responsif

🎨 Kombinasi Grid + Typography

Inilah tampilan nyata ketika Grid dan Typography digabungkan dalam satu halaman.

📚 Materi Web Design II

Semester Genap 2025/2026 — Pertemuan 6

📐 Responsive Grid

Sistem 12 kolom Bootstrap yang menyesuaikan ukuran layar secara otomatis.

🔤 Typography

Class-class Bootstrap untuk mempercantik tampilan teks dan konten tertulis.

💡 Best Practice

Selalu mulai dari mobile dulu, lalu sesuaikan untuk tablet dan desktop.

"Design is not just what it looks like. Design is how it works — across all devices."

— Steve Jobs

Hal yang sudah kita pelajari hari ini:

  • Responsive breakpoints: sm, md, lg, xl
  • Penulisan class col-12, col-md-6, col-lg-4
  • Typography: text-muted, address, code, blockquote, list
🎯
Kunci Kombinasi
Grid mengatur posisi elemen. Typography mengatur gaya konten. Keduanya bekerja bersama untuk halaman yang rapi, readable, dan responsif.
HTML — Kombinasi Lengkap
<div class="container">
  <h2>Judul Konten</h2>
  <p class="lead text-muted">Deskripsi singkat</p>

  <div class="row">
    <div class="col-12 col-md-4">Kolom 1</div>
    <div class="col-12 col-md-4">Kolom 2</div>
    <div class="col-12 col-md-4">Kolom 3</div>
  </div>

  <blockquote class="blockquote">
    <p>Kutipan inspiratif...</p>
    <footer class="blockquote-footer">Sumber</footer>
  </blockquote>

  <ul>
    <li>Item pertama</li>
    <li>Item kedua</li>
  </ul>
</div>
Section 12

⚠️ Kesalahan Umum yang Sering Terjadi

Hindari 3 kesalahan ini agar layoutmu tidak berantakan!

❌
Lupa col-12 di Mobile
Tanpa col-12, elemen tidak akan full-width di layar HP. Layout bisa sempit atau terpotong.
❌ class="col-md-6 col-lg-4"
✅ class="col-12 col-md-6 col-lg-4"
❌
Urutan Breakpoint Terbalik
Bootstrap mobile-first. Urutan benar: tanpa prefix dulu, lalu sm, md, lg, xl.
❌ class="col-lg-4 col-12 col-md-6"
✅ class="col-12 col-md-6 col-lg-4"
❌
Total Kolom Melebihi 12
Total unit kolom dalam 1 row tidak boleh melebihi 12. Jika lebih, kolom akan "wrap" ke bawah secara tidak terduga.
❌ col-5 + col-5 + col-5 = 15 unit ✗
✅ col-4 + col-4 + col-4 = 12 unit ✓
