Topik 1

Contextual Color

Kelas Bootstrap untuk mengatur warna teks sesuai konteks semantik.

Penjelasan Teori

Bootstrap 4 menyediakan serangkaian class utilitas untuk mengubah warna teks secara langsung menggunakan sistem warna semantik. Class-class ini sangat berguna untuk menyampaikan makna atau status informasi kepada pengguna secara visual.

Warna yang digunakan mengikuti palet warna Bootstrap yang konsisten, sehingga tampilan tetap harmonis tanpa perlu menulis CSS tambahan.

ClassKeteranganContoh Warna
.text-primaryBiru – aksi utama, link penting■ Primary
.text-secondaryAbu – informasi sekunder■ Secondary
.text-successHijau – berhasil, positif■ Success
.text-dangerMerah – error, peringatan kritis■ Danger
.text-warningKuning – peringatan, perhatian■ Warning
.text-infoCyan – informasi tambahan■ Info
.text-lightPutih muda – untuk latar gelap■ Light
.text-darkHitam – teks standar kuat■ Dark
.text-mutedAbu redup – teks pendukung■ Muted
.text-whitePutih – untuk latar warna■ White
HTML 
<p class="text-primary">Teks warna Primary (Biru)</p>
<p class="text-secondary">Teks warna Secondary (Abu)</p>
<p class="text-success">Teks warna Success (Hijau)</p>
<p class="text-danger">Teks warna Danger (Merah)</p>
<p class="text-warning">Teks warna Warning (Kuning)</p>
<p class="text-info">Teks warna Info (Cyan)</p>
<p class="text-muted">Teks warna Muted (Abu Redup)</p>
<p class="text-dark">Teks warna Dark (Hitam)</p>
<p class="bg-dark text-white">Teks White pada background gelap</p>
<p class="bg-dark text-light">Teks Light pada background gelap</p>

Class .text-white dan .text-light sebaiknya digunakan bersama background berwarna seperti .bg-dark atau .bg-primary agar teks tetap terbaca.

Topik 3

Icon

Menggunakan Font Awesome sebagai alternatif icon di Bootstrap 4.

Penjelasan Teori

Berbeda dengan Bootstrap 3 yang menyertakan Glyphicon secara bawaan, Bootstrap 4 tidak lagi menyertakan icon secara default. Keputusan ini diambil untuk mengurangi ukuran framework dan memberikan fleksibilitas kepada developer untuk memilih library icon sesuai kebutuhan.

Alternatif yang paling populer dan direkomendasikan adalah Font Awesome, yang dapat dimuat melalui CDN tanpa instalasi tambahan. Font Awesome menyediakan ribuan icon SVG dan font-based yang dapat digunakan secara gratis.

Tambahkan CDN berikut di dalam tag <head> untuk menggunakan Font Awesome:
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css">

Cara penggunaan: cukup tambahkan tag <i> atau <span> dengan class yang sesuai. Class dimulai dengan fas (solid), far (regular), atau fab (brand).

HTML 
<!-- Icon Dasar -->
<i class="fas fa-home"></i> Home
<i class="fas fa-user"></i> User
<i class="fas fa-envelope"></i> Email
<i class="fas fa-check"></i> Ceklis
<i class="fas fa-times"></i> Tutup

<!-- Ubah Ukuran dengan fa-lg, fa-2x, fa-3x -->
<i class="fas fa-star fa-lg"></i>
<i class="fas fa-star fa-2x"></i>
<i class="fas fa-star fa-3x"></i>

<!-- Kombinasi dengan class Bootstrap -->
<i class="fas fa-bell text-warning fa-2x"></i>
<i class="fas fa-shield-alt text-success fa-2x"></i>
<i class="fab fa-github text-dark fa-2x"></i>

Topik 4

Clearfix

Mengatasi masalah float collapse pada elemen yang menggunakan float.

Penjelasan Teori

Ketika elemen anak (child) menggunakan properti CSS float, elemen induk (parent) tidak otomatis menyesuaikan tingginya. Hal ini menyebabkan float collapse – di mana container parent seolah "runtuh" karena tidak mengenali tinggi anak float-nya.

Bootstrap 4 menyediakan class .clearfix yang dapat ditambahkan pada elemen parent/container untuk mengatasi masalah ini. Class ini bekerja dengan teknik CSS clearfix hack menggunakan pseudo-element ::after.

Kapan pakai clearfix? Gunakan saat elemen-elemen di dalam container menggunakan float: left atau float: right dan container tidak "memeluk" elemen tersebut.
HTML – Tanpa Clearfix (Bermasalah) 
<!-- ❌ Tanpa clearfix: container "runtuh" -->
<div style="border: 2px solid red;">
  <div style="float: left; background: #cce5ff; padding: 10px;">Float Kiri</div>
  <div style="float: right; background: #d4edda; padding: 10px;">Float Kanan</div>
</div>

<!-- ✅ Dengan clearfix: container mengikuti tinggi isi -->
<div class="clearfix" style="border: 2px solid green;">
  <div style="float: left; background: #cce5ff; padding: 10px;">Float Kiri</div>
  <div style="float: right; background: #d4edda; padding: 10px;">Float Kanan</div>
</div>

Topik 5

Menampilkan & Menyembunyikan Konten

Utility class Bootstrap untuk mengontrol visibilitas dan tipe display elemen.

Penjelasan Teori

Bootstrap 4 menyediakan class display utility yang sangat fleksibel untuk mengontrol tampilan elemen. Class-class ini menggunakan format d-{value} atau d-{breakpoint}-{value} untuk kontrol responsif per ukuran layar.

ClassSetara CSSKeterangan
.d-nonedisplay: noneSembunyikan elemen di semua ukuran
.d-blockdisplay: blockTampilkan sebagai block
.d-inlinedisplay: inlineTampilkan sebagai inline
.d-inline-blockdisplay: inline-blockGabungan inline dan block
.d-flexdisplay: flexAktifkan flexbox
.d-sm-none— (≥576px)Sembunyikan di layar ≥ SM
.d-md-block— (≥768px)Tampilkan block di layar ≥ MD
.d-lg-none— (≥992px)Sembunyikan di layar ≥ LG

Pola umum untuk hanya tampil di mobile: d-block d-md-none
Pola umum untuk hanya tampil di desktop: d-none d-md-block

HTML 
<!-- Hanya tampil di mobile (layar kecil) -->
<div class="d-block d-md-none alert alert-warning">
  Konten ini hanya tampil di layar mobile! 📱
</div>

<!-- Hanya tampil di desktop (md ke atas) -->
<div class="d-none d-md-block alert alert-success">
  Konten ini hanya tampil di desktop! 🖥️
</div>

<!-- d-flex untuk membuat layout flex -->
<div class="d-flex justify-content-between">
  <div class="bg-primary text-white p-2">Kiri</div>
  <div class="bg-success text-white p-2">Tengah</div>
  <div class="bg-danger text-white p-2">Kanan</div>
</div>

<!-- d-inline-block untuk item berjajar -->
<div class="d-inline-block bg-info text-white p-2">Item 1</div>
<div class="d-inline-block bg-warning text-dark p-2">Item 2</div>

Topik 6

Screen Reader

Kelas aksesibilitas Bootstrap untuk mendukung pengguna dengan screen reader.

Penjelasan Teori

Aksesibilitas web (web accessibility) adalah praktik membuat halaman web yang dapat digunakan oleh semua orang, termasuk pengguna dengan disabilitas visual yang menggunakan alat bantu seperti screen reader (pembaca layar).

Screen reader membaca konten halaman web secara tekstual kepada pengguna. Kadang kita ingin menambahkan teks keterangan yang hanya dibaca oleh screen reader tanpa ditampilkan secara visual.

ClassKeterangan
.sr-onlySembunyikan elemen secara visual, tapi tetap dapat dibaca screen reader. Menggunakan teknik CSS khusus (bukan display:none yang akan menyembunyikan dari semua)
.sr-only-focusableSama seperti .sr-only, tetapi elemen akan muncul kembali saat difokus (misalnya saat navigasi keyboard). Berguna untuk "skip to content" link.
Perbedaan penting: display: none atau visibility: hidden menyembunyikan elemen dari SEMUA pengguna termasuk screen reader. Sedangkan .sr-only hanya menyembunyikan secara visual.
HTML 
<!-- Tombol dengan icon saja + keterangan untuk screen reader -->
<button class="btn btn-primary">
  <i class="fas fa-search"></i>
  <span class="sr-only">Tombol Cari</span>
</button>

<!-- Skip to content link (focusable saat navigasi keyboard) -->
<a class="sr-only sr-only-focusable" href="#main-content">
  Skip ke konten utama
</a>

<!-- Label form tersembunyi untuk screen reader -->
<form>
  <label class="sr-only" for="searchInput">Kolom Pencarian</label>
  <input type="text" id="searchInput" 
         class="form-control" 
         placeholder="Cari...">
</form>

Topik 7

Image Replacement

Teknik aksesibilitas untuk menggantikan teks dengan gambar secara visual.

Penjelasan Teori

Image Replacement adalah teknik di mana teks pada elemen HTML digantikan secara visual oleh sebuah gambar (misalnya logo), namun teks aslinya tetap ada dalam kode HTML agar dapat dibaca oleh screen reader dan mesin pencari (SEO).

Bootstrap 4 menyediakan class .text-hide untuk keperluan ini. Class ini menyembunyikan teks menggunakan teknik CSS khusus (bukan display:none) sambil tetap menampilkan background-image yang ditetapkan.

ClassKeterangan
.text-hideSembunyikan teks elemen secara visual, biasanya dipakai bersama background-image untuk menampilkan logo atau gambar.
Catatan: Sejak Bootstrap 5, class .text-hide telah dihapus karena tidak lagi dianggap praktik terbaik. Untuk Bootstrap 4, class ini masih tersedia namun penggunaannya disarankan hati-hati.
HTML + CSS 
<!-- CSS -->
<style>
  .logo-header {
    background-image: url('logo.png');
    background-size: contain;
    background-repeat: no-repeat;
    width: 150px;
    height: 50px;
    display: block;
  }
</style>

<!-- HTML: Teks "Nama Website" disembunyikan, logo tampil -->
<a href="/" class="logo-header text-hide">
  Nama Website
</a>

<!-- Contoh dengan heading -->
<h1 class="logo-header text-hide">Nama Website</h1>

Topik 8

Responsive Utility

Sistem breakpoint Bootstrap 4 untuk tampilan yang adaptif di berbagai ukuran layar.

Penjelasan Teori

Bootstrap 4 menggunakan sistem breakpoint untuk menentukan batas ukuran layar. Class-class responsive memungkinkan kita menampilkan atau menyembunyikan elemen berdasarkan ukuran layar pengguna.

BreakpointPrefixLebar Layar
Extra Small- (default)< 576px (HP kecil)
Small-sm-≥ 576px (HP besar)
Medium-md-≥ 768px (Tablet)
Large-lg-≥ 992px (Laptop)
Extra Large-xl-≥ 1200px (Monitor)

Pola penggunaan umum:

  • d-none d-md-block → Hanya tampil di layar MD ke atas (tablet/desktop)
  • d-block d-md-none → Hanya tampil di layar di bawah MD (mobile)
  • d-none d-sm-block d-lg-none → Tampil hanya di SM – LG
HTML 
<!-- Hanya muncul di mobile -->
<div class="d-block d-sm-none alert alert-info">
  📱 Tampilan Mobile (XS)
</div>

<!-- Hanya muncul di SM –– MD -->
<div class="d-none d-sm-block d-md-none alert alert-success">
  📲 Tampilan Small (SM) — Tablet kecil
</div>

<!-- Hanya muncul di MD ke atas -->
<div class="d-none d-md-block alert alert-warning">
  🖥️ Tampilan Medium (MD) ke atas — Tablet / Desktop
</div>

<!-- Hanya muncul di LG ke atas -->
<div class="d-none d-lg-block alert alert-danger">
  🖥️ Tampilan Large (LG) — Laptop / Desktop besar
</div>

<!-- Grid responsif -->
<div class="row">
  <div class="col-12 col-md-6 col-lg-4">Kolom A</div>
  <div class="col-12 col-md-6 col-lg-4">Kolom B</div>
  <div class="col-12 col-md-12 col-lg-4">Kolom C</div>
</div>

Tugas Praktik Pertemuan 10

Helper Class Bootstrap 4.0 · Pemrograman Web

Studi Kasus

Buatlah sebuah halaman web profil mahasiswa menggunakan Bootstrap 4 yang mencakup semua helper class yang telah dipelajari, dengan ketentuan sebagai berikut:

Ketentuan Tugas

1
Gunakan Contextual Color untuk menampilkan nama, jurusan, dan status mahasiswa dengan warna yang berbeda sesuai konteks. (contoh: nama dengan text-primary, status aktif dengan text-success)
2
Gunakan Contextual Background untuk membuat card/section informasi dengan background berwarna. (contoh: card nilai dengan bg-success, card peringatan dengan bg-warning)
3
Tambahkan minimal 5 Icon Font Awesome yang relevan dengan konten profil. Contoh: icon untuk email (fa-envelope), telepon (fa-phone), lokasi (fa-map-marker-alt), jurusan (fa-graduation-cap), media sosial (fab fa-instagram), dll.
4
Gunakan Clearfix untuk mengatur layout yang menggunakan float. Misalnya foto profil di-float ke kiri dan teks biodata di sebelah kanannya, container diberi class .clearfix.
5
Terapkan fitur Menampilkan dan Menyembunyikan Konten — buat minimal 1 elemen yang hanya tampil di layar tertentu. Contoh: tombol lengkap hanya tampil di desktop (d-none d-md-block), tombol icon tampil di mobile (d-block d-md-none).
6
Tambahkan elemen Screen Reader menggunakan .sr-only minimal 1 buah untuk keperluan aksesibilitas. Contoh: label tersembunyi pada tombol icon, atau keterangan tambahan pada elemen navigasi.
7
Gunakan Image Replacement (.text-hide) pada logo atau header halaman — teks judul disembunyikan secara visual namun tetap ada di kode HTML untuk screen reader dan SEO.
8
Terapkan Responsive Utility agar layout halaman menyesuaikan tampilan di mobile dan desktop. Gunakan kombinasi class display seperti d-none d-md-block dan grid system Bootstrap yang responsif.

Format Pengumpulan

File: index.html (single file)
Media: LMS / Google Classroom
Deadline: Sesuai jadwal dosen
Seluruh CSS dan JavaScript harus ditulis dalam satu file HTML. CDN Bootstrap 4 dan Font Awesome diperbolehkan. Tidak ada file eksternal lainnya.
