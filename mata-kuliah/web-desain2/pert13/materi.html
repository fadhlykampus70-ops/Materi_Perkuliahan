Plugin JavaScript Bootstrap 4 & Responsive Web Design

Materi ini menggabungkan Pertemuan 12, 13, dan 14 — mengenal komponen interaktif Bootstrap yang digerakkan JavaScript, lalu menerapkannya dalam studi kasus nyata: Sistem Informasi Kampus.

Cara pakai materi ini: Setiap komponen punya kotak kode yang bisa Anda lihat tab HTML/CSS/JS-nya, dan kotak hijau "Live Demo" di bawahnya yang elemennya benar‑benar aktif — bisa langsung diklik, hover, atau dicoba saat ini juga tanpa pindah file.
Prasyarat wajib: Semua plugin JavaScript Bootstrap 4 di bawah ini hanya akan berfungsi jika 3 file ini dimuat secara berurutan: jQuery → Popper.js → bootstrap.min.js. Tanpa jQuery dan Popper, atribut data-toggle tidak akan bekerja sama sekali.

Bagian 1 · Plugin Dasar

Transitions

Pertemuan 12

Analogi: Bayangkan Anda membuka pintu lemari. Pintu itu tidak langsung "hilang" lalu "muncul" terbuka — ia bergerak halus dari posisi tertutup ke posisi terbuka. Transitions di Bootstrap adalah "engsel" yang membuat perubahan tampilan (muncul/hilang, geser, pudar) terasa halus, bukan tiba‑tiba.

Transition bukan komponen yang berdiri sendiri — ia adalah modul dasar (base module) yang dipakai oleh hampir semua plugin lain: Modal saat muncul/hilang, Dropdown saat terbuka, Alert saat ditutup, Tab saat berpindah — semuanya memanfaatkan efek transisi CSS yang disediakan modul ini secara otomatis.

Bootstrap mendeteksi dukungan transisi CSS3 di browser secara otomatis. Jika browser tidak mendukung (sangat jarang di browser modern), Bootstrap akan menggantinya dengan perubahan langsung tanpa animasi — jadi komponen tetap berfungsi, hanya tidak halus.

Contoh Efek Transition (fade)

<div class="box-transition" id="boxFade">
  Klik tombol untuk melihat efek fade
</div>
<button onclick="document.getElementById('boxFade').classList.toggle('show')">
  Toggle Fade
</button>
/* Inilah inti dari "transition": */
.box-transition {
  opacity: 0;
  transition: opacity 0.4s linear; /* <-- bagian penting */
}
.box-transition.show {
  opacity: 1;
}

Modal

Pertemuan 12

Analogi: Modal itu seperti kertas pengumuman yang ditempel di atas meja kerja Anda — semua yang di bawahnya jadi "ter-blok" sementara, dan Anda harus fokus membaca atau menutup pengumuman itu dulu sebelum lanjut kerja. Itulah Modal: kotak dialog yang muncul di atas konten, melayang, dengan latar belakang gelap (backdrop) di belakangnya.

Modal biasa dipakai untuk: konfirmasi sebelum hapus data, menampilkan form login/daftar tanpa pindah halaman, menampilkan detail gambar atau info tambahan, atau peringatan penting yang wajib dibaca pengguna.

Contoh Penerapan

Modal diaktifkan lewat atribut data-toggle="modal" dan data-target="#idModal" — tanpa satu baris JavaScript pun dari kita, karena logikanya sudah dibungkus di dalam bootstrap.min.js.

<!-- Tombol pemicu -->
<button type="button" class="btn btn-primary"
  data-toggle="modal" data-target="#modalContoh">
  Buka Modal
</button>

<!-- Struktur Modal -->
<div class="modal fade" id="modalContoh" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Judul Modal</h5>
        <button class="close" data-dismiss="modal">&times;</button>
      </div>
      <div class="modal-body">
        Isi konten modal di sini.
      </div>
      <div class="modal-footer">
        <button class="btn btn-secondary" data-dismiss="modal">Tutup</button>
      </div>
    </div>
  </div>
</div>

Dropdown

Pertemuan 12

Analogi: Dropdown itu seperti laci kecil di meja. Saat tertutup, laci tidak memakan tempat. Begitu dibuka (diklik), isi di dalamnya baru terlihat — lalu Anda bisa pilih satu barang dan laci otomatis tertutup lagi.

Dropdown menampilkan daftar pilihan/menu yang tersembunyi sampai elemen pemicunya (biasanya tombol atau link) diklik. Sangat umum dipakai untuk menu navigasi bertingkat, menu akun pengguna, atau filter pilihan.

<div class="dropdown">
  <button class="btn btn-primary dropdown-toggle"
    type="button" data-toggle="dropdown">
    Menu Akun
  </button>
  <div class="dropdown-menu">
    <a class="dropdown-item" href="#">Profil</a>
    <a class="dropdown-item" href="#">Pengaturan</a>
    <div class="dropdown-divider"></div>
    <a class="dropdown-item" href="#">Keluar</a>
  </div>
</div>

Scrollspy

Pertemuan 12

Analogi: Sidebar navigasi di sebelah kiri halaman materi ini sebenarnya menggunakan prinsip yang sama dengan Scrollspy — seperti GPS yang terus memantau "Anda sedang di mana" dan menyalakan penanda lokasi saat ini secara otomatis sambil Anda bergerak (scroll).

Scrollspy secara otomatis memperbarui link navigasi berdasarkan posisi scroll halaman, menandai menu yang sesuai dengan section yang sedang dilihat pengguna sebagai "aktif".

<!-- Ditempelkan pada elemen body atau container yang scroll -->
<body data-spy="scroll" data-target="#navSpy" data-offset="60">

<nav id="navSpy">
  <a class="nav-link" href="#bagian1">Bagian 1</a>
  <a class="nav-link" href="#bagian2">Bagian 2</a>
</nav>

Bagian 2 · Plugin Interaktif

Tab

Pertemuan 13

Analogi: Tab seperti sekat-sekat pembatas (divider) dalam satu folder ring binder — semua kertas ada di dalam satu folder yang sama, tapi Anda hanya melihat satu sekat/bagian dalam satu waktu, dan tinggal klik label sekat lain untuk berpindah.

Tab Plugin memungkinkan beberapa panel konten berbagi satu area tampilan, di mana hanya satu panel yang terlihat dalam satu waktu, dikendalikan oleh navigasi label di atasnya.

Fade Effect

Tambahkan class fade pada elemen .tab-pane agar perpindahan antar tab terasa halus (transisi opacity), bukan langsung berganti secara kasar.

<ul class="nav nav-tabs" role="tablist">
  <li class="nav-item">
    <a class="nav-link active" data-toggle="tab" href="#tabInfo">Info</a>
  </li>
  <li class="nav-item">
    <a class="nav-link" data-toggle="tab" href="#tabJadwal">Jadwal</a>
  </li>
</ul>

<div class="tab-content">
  <div class="tab-pane fade show active" id="tabInfo">
    Konten Info di sini.
  </div>
  <div class="tab-pane fade" id="tabJadwal">
    Konten Jadwal di sini.
  </div>
</div>

Bagian 2 · Plugin Interaktif

Tooltip

Pertemuan 13

Analogi: Tooltip seperti label kecil sticky note yang muncul sesaat saat jari/kursor Anda mengarah pada sebuah tombol — memberi keterangan singkat tanpa harus membuka halaman atau jendela baru.

Tooltip menampilkan teks bantuan singkat saat pengguna mengarahkan kursor (hover) atau fokus ke suatu elemen. Cocok untuk menjelaskan ikon tanpa label, atau memberi info tambahan tanpa memenuhi tampilan.

Wajib diingat: Tooltip tidak otomatis aktif hanya dengan menulis atributnya di HTML. Harus diinisialisasi lewat JavaScript: $('[data-toggle="tooltip"]').tooltip() — ini adalah plugin yang paling sering terlewat diinisialisasi oleh mahasiswa.
<button class="btn btn-secondary" data-toggle="tooltip"
  data-placement="top" title="Ini adalah tooltip">
  Arahkan kursor ke sini
</button>
// Wajib dipanggil agar tooltip aktif!
$('[data-toggle="tooltip"]').tooltip();

Popover

Pertemuan 13

Analogi: Jika Tooltip adalah sticky note kecil dengan satu baris kalimat, Popover adalah kartu info yang lebih besar lengkap dengan judul dan isi paragraf — seperti kartu nama yang muncul saat Anda mengklik foto profil seseorang.

Popover serupa dengan Tooltip, tetapi mendukung konten yang lebih kaya: judul (header) terpisah dan body yang lebih panjang. Umumnya dipicu dengan klik, bukan hover.

<button class="btn btn-primary" data-toggle="popover"
  title="Dikenakan Sanksi" data-content="Keterlambatan lebih dari 15 menit dianggap alpa.">
  Lihat Aturan
</button>
// Sama seperti tooltip, popover wajib diinisialisasi:
$('[data-toggle="popover"]').popover();

Alert

Pertemuan 13

Analogi: Alert seperti pengumuman tempel di papan mading sekolah — bisa berwarna sesuai jenis info (hijau = baik, merah = bahaya), dan biasanya ada yang bisa "dicabut/ditutup" setelah dibaca dengan tombol silang.

Alert menampilkan pesan kontekstual untuk memberi tahu pengguna tentang suatu kondisi (berhasil, gagal, peringatan, info), dan plugin JS-nya menambahkan kemampuan untuk menutup alert tersebut dengan animasi fade.

<div class="alert alert-success alert-dismissible fade show" role="alert">
  Data berhasil disimpan!
  <button type="button" class="close" data-dismiss="alert">&times;</button>
</div>

Bagian 2 · Plugin Interaktif

Button

Pertemuan 13

Analogi: Button Plugin seperti saklar lampu kamar — ada yang bersifat satu tombol on/off (Single Toggle), ada yang berkelompok seperti memilih satu dari beberapa channel TV (Radio), dan ada yang bisa pilih banyak sekaligus seperti centang daftar belanja (Checkbox).

Button Plugin menambahkan perilaku tambahan pada elemen <button>: status "loading" sementara proses berjalan, toggle aktif/nonaktif, dan pengelompokan checkbox/radio bergaya tombol.

Loading State

Mengganti teks tombol sementara menjadi indikator "memuat" menggunakan atribut data-loading-text, lalu dikembalikan lagi via JS.

<button id="btnSimpan" class="btn btn-primary" data-loading-text="Menyimpan...">
  Simpan Data
</button>
$('#btnSimpan').on('click', function () {
  $(this).button('loading');   // ganti jadi "Menyimpan..."
  setTimeout(() => {
    $(this).button('reset');    // kembalikan ke teks asli
  }, 1500);
});

Bagian 3 · Studi Kasus

Responsive Web Design

Pertemuan 14

Analogi: Bayangkan air yang dituang ke gelas apa pun — gelas tinggi, gelas lebar, botol kecil — air akan selalu menyesuaikan bentuknya dengan wadahnya. Itulah prinsip Responsive Web Design (RWD): tampilan website "menyesuaikan diri" dengan ukuran layar perangkat yang dipakai (HP, tablet, laptop, monitor besar), bukan dipaksa satu ukuran untuk semua.

Mulai dari sini, kita masuk ke studi kasus utuh: membangun bagian-bagian dari sebuah Sistem Informasi Kampus statis yang responsif, menggabungkan komponen Bootstrap (grid, navbar, carousel, card) dengan prinsip RWD.

Mengapa Bootstrap memudahkan RWD? Karena sistem grid Bootstrap (.container, .row, .col-*) dan breakpoint bawaannya (sm, md, lg, xl) sudah dirancang mobile‑first — kita cukup menambahkan class yang sesuai, tanpa menulis banyak @media query secara manual.

col-sm-≥ 576pxHP besar / landscape

Navbar

Pertemuan 14

Analogi: Navbar adalah etalase depan toko — bagian pertama yang dilihat pengunjung, menunjukkan "ruangan apa saja yang ada di dalam" sebelum mereka masuk lebih jauh.

Navbar adalah komponen navigasi utama di bagian atas halaman. Pada layar kecil, Navbar otomatis "terlipat" menjadi ikon hamburger (☰) berkat plugin Collapse yang bekerja sama dengan class navbar-expand-*.

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <a class="navbar-brand" href="#">SI Kampus</a>
  <button class="navbar-toggler" data-toggle="collapse" data-target="#navMain">
    <span class="navbar-toggler-icon"></span>
  </button>

  <div class="collapse navbar-collapse" id="navMain">
    <ul class="navbar-nav ml-auto">
      <li class="nav-item active"><a class="nav-link" href="#">Home</a></li>
      <li class="nav-item"><a class="nav-link" href="#">Akademik</a></li>
    </ul>
  </div>
</nav>

Sidebar Layout

Pertemuan 14

Analogi: Sidebar seperti rak buku referensi di pojok ruang perpustakaan — selalu berada di tempat yang sama, berisi daftar kategori yang membantu Anda berpindah antar bagian tanpa harus keluar ruangan.

Sidebar bukan plugin JavaScript Bootstrap tersendiri, melainkan pola layout yang dibangun dari grid Bootstrap (.col-*) digabung CSS sederhana, sering dipakai untuk halaman dashboard/admin seperti menu Akademik, KRS, dan Nilai pada Sistem Informasi Kampus.

<div class="row no-gutters">
  <div class="col-md-3 sidebar-panel">
    <a class="d-block py-2" href="#">Dashboard</a>
    <a class="d-block py-2" href="#">KRS</a>
    <a class="d-block py-2" href="#">Nilai</a>
  </div>
  <div class="col-md-9">
    Konten utama halaman di sini.
  </div>
</div>
.sidebar-panel {
  background: #f8f9fa;
  border-right: 1px solid #dee2e6;
  min-height: 100%;
}
/* Pada layar kecil (di bawah md), col-md-3 otomatis
   menjadi full-width dan "turun" ke bawah/atas konten
   — inilah keajaiban grid mobile-first Bootstrap */
