Visi Jurusan

Mencetak tenaga ahli di bidang teknologi informasi yang kompeten dan berdaya saing.

Program studi MI berfokus pada pengembangan sistem informasi, pemrograman web, dan manajemen basis data. Lulusan kami siap bekerja di industri teknologi maupun berwirausaha.

Pemrograman Web

Belajar HTML, CSS, JavaScript, dan framework modern untuk membangun aplikasi web profesional.

Teknologi: HTML5, CSS3, Bootstrap

Basis Data

Merancang dan mengelola database relasional menggunakan SQL dan sistem manajemen database modern.

Teknologi: MySQL, PostgreSQL

Jaringan Komputer

Memahami konsep jaringan, protokol komunikasi, dan keamanan sistem jaringan komputer.

Tools: Cisco Packet Tracer
