Apa itu Perulangan?
Konsep dasar yang wajib dikuasai

Bayangin kamu lagi nyapu halaman. Kamu sapu satu garis, terus balik, sapu lagi, terus balik lagi... sampai semua lantai bersih. Itu namanya perulangan — melakukan aksi yang sama berulang kali sampai kondisi tertentu terpenuhi.


Dalam pemrograman, kalau kita mau cetak angka 1 sampai 100, masa kita mau nulis cout sebanyak 100 baris? Nggak mungkin, kan! Di sinilah loop jadi penyelamat.

🍳 Analogi Kehidupan Sehari-hari
  • Mengisi daftar hadir → absen satu-satu sampai semua nama dipanggil
  • Memasak mie → aduk terus sampai matang (kondisi: matang)
  • Nonton drama Korea → episode 1, 2, 3... sampai tamat (jumlahnya pasti)
  • Nunggu SMS balasan → cek HP terus sampai ada notif masuk (kondisi: ada notif)
Kenapa butuh loop?
1
Efisiensi kode

Daripada nulis 100 baris, cukup 3–5 baris pakai loop

2
Otomatisasi

Komputer bisa mengulang jutaan kali tanpa capek

3
Fleksibel

Bisa disesuaikan dengan kondisi yang berubah-ubah

FOR Loop
Dipakai kalau sudah tahu mau berapa kali ulang
🎯 Kapan pakai FOR? Ketika kamu sudah tahu pasti berapa kali program harus diulang. Contoh: "cetak 5 kali", "tampilkan 10 data", "ulang sebanyak n kali".
Struktur Umum
C++ Syntax 
for (inisialisasi ; kondisi ; perubahan) {
    // kode yang diulang
}
Inisialisasi
Nilai awal variabel
int i = 0
Kondisi
Syarat lanjut loop
i <= 5
Perubahan
Update setiap iterasi
i++
Contoh: Tampilkan Angka 1 – 5
Pseudocode
MULAI

    TAMPILKAN i
  AKHIR UNTUK

C++
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << "Angka: " << i << endl;
    }
    return 0;
}

WHILE Loop
Dipakai kalau belum tahu pasti berapa kali — tergantung kondisi
🎯 Kapan pakai WHILE? Ketika loop bergantung pada kondisi yang bisa berubah, bukan jumlah pasti. Kondisi dicek di awal sebelum isi loop dijalankan.

Struktur Umum
C++ Syntax
while (kondisi) {

DO-WHILE Loop
Dijalankan minimal 1 kali, baru dicek kondisinya
🎯 Bedanya sama while biasa? Di while, kondisi dicek sebelum loop jalan. Di do-while, loop dijalankan DULU baru dicek kondisi di akhir. Jadi minimal pasti 1 kali jalan!
WHILE
while (kondisi) {
  // cek dulu baru jalan
}
❌ Bisa saja 0 kali jalan
kalau kondisi false dari awal
DO-WHILE
do {
  // jalan dulu baru cek
} while (kondisi);
✅ Dijamin minimal 1 kali
walaupun kondisi false
Contoh: Menu yang tampil minimal sekali
Pseudocode
MULAI
  LAKUKAN
    TAMPILKAN "Masukkan angka (1-5): "
    BACA angka
  SELAMA angka < 1 ATAU angka > 5
  TAMPILKAN "Angka valid: " + angka
SELESAI
C++
int angka;

do {
    cout << "Masukkan angka (1-5): ";
    cin >> angka;
    if (angka < 1 || angka > 5)
        cout << "❌ Angka salah! Coba lagi." << endl;
} while (angka < 1 || angka > 5);

cout << "✅ Angka valid: " << angka;

NESTED Loop
Loop di dalam loop — seperti boneka matryoshka!
🪆 Analogi Nested Loop
Bayangkan kamu punya 3 kelas (kelas A, B, C). Di setiap kelas ada 5 siswa. Untuk absen semua siswa, kamu harus: untuk setiap kelas → untuk setiap siswa di kelas itu → panggil namanya. Itu nested loop!
Struktur Umum
C++ — Nested Loop
for (int i = 1; i <= baris; i++) {      // loop luar
    for (int j = 1; j <= i; j++) {   // loop dalam
        cout << "* ";
    }
    cout << endl;   // pindah baris
}
💡 Cara Bacanya: Untuk setiap 1 putaran loop luar → loop dalam berputar PENUH dari awal sampai akhir. Jadi total iterasi = baris_luar × kolom_dalam.
Contoh: Pola Segitiga Bintang
C++
int n = 5;   // jumlah baris

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        cout << "* ";
    }
    cout << endl;
}

BREAK & CONTINUE
Kontrol alur loop secara lebih spesifik
⛔
BREAK

Menghentikan loop secara paksa. Begitu ketemu break, loop langsung berhenti total dan program lanjut ke baris setelah loop.

Ibarat: Kamu lagi antri kasir, tapi tiba-tiba pingsan → keluar dari antrian seketika!
⏭️
CONTINUE

Melewati iterasi yang sedang berjalan dan lanjut ke iterasi berikutnya. Loop tidak berhenti, hanya satu putaran itu yang dilewati.

Ibarat: Antri kasir, sampai giliran kamu tapi barangmu lupa → skip dulu, orang berikutnya jalan!

Loop 1–10, tapi berhenti begitu ketemu angka 6:

C++ — break
for (int i = 1; i <= 10; i++) {
    if (i == 6) {
        cout << "Berhenti di " << i << endl;
        break;    // keluar dari loop!
    }
    cout << i << " ";
}
// Output: 1 2 3 4 5 Berhenti di 6
Output
1 2 3 4 5 Berhenti di 6

Loop 1–10, tapi lewati (skip) angka genap:

C++ — continue
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;  // skip angka genap
    }
    cout << i << " ";
}
// Output: 1 3 5 7 9
Output
1 3 5 7 9

Ringkasan Materi
Poin penting yang harus diingat
🔁

for loop

Pakai saat jumlah iterasi sudah diketahui pasti. Counter ada di dalam deklarasi for.

🔄

while loop

Pakai saat bergantung kondisi yang bisa berubah. Cek kondisi di awal. Bisa 0 kali jalan.

🔃

do-while

Minimal 1 kali pasti jalan. Kondisi dicek di akhir. Cocok untuk validasi input.

🪆

nested loop

Loop di dalam loop. Total iterasi = luar × dalam. Sering dipakai untuk pola/matriks.

⛔⏭️

break & continue

break = hentikan total. continue = lewati iterasi ini, lanjut ke berikutnya.

🎓 Tips Belajar dari Dosen
💡
Trace manual dulu

Sebelum langsung coding, lacak iterasi di kertas. Tulis nilai variabel di setiap langkah.

🔧
Mulai dari yang kecil

Coba dulu loop 1-3, pastikan benar, baru tambah range-nya.

⚠️
Waspada infinite loop

Selalu pastikan ada kondisi yang akan menjadi false, terutama di while dan do-while.
