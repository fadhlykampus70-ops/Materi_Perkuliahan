01 — KONSEP DASAR
Apa itu Mengurutkan Data (Sorting)?
Sebelum masuk ke algoritmanya, pahami dulu masalah yang ingin diselesaikan dan kenapa cara mengurutkannya itu penting.
📦
Definisi Sederhana
Mengatur ulang posisi data dalam sebuah list

Sorting adalah proses menyusun ulang elemen-elemen dalam sebuah kumpulan data (list/array) agar urutannya sesuai aturan tertentu — biasanya dari yang terkecil ke terbesar (ascending) atau dari yang terbesar ke terkecil (descending).

💡
Contoh sehari-hari: nilai mahasiswa diurutkan dari yang tertinggi untuk menentukan ranking, atau daftar harga produk diurutkan dari yang termurah saat kamu belanja online.
🤔
Mengapa Sorting Penting?
1
Memudahkan pencarian data
Data yang sudah urut bisa dicari lebih cepat (misal dengan binary search).
2
Memudahkan analisis
Menentukan nilai terbesar, terkecil, atau ranking jadi lebih mudah dibaca.
3
Tampilan data lebih rapi
Laporan, tabel, dan daftar jadi lebih nyaman dibaca pengguna.
⚙️
Dua Algoritma yang Kita Bahas

Ada banyak algoritma sorting. Hari ini kita fokus ke dua algoritma paling dasar yang cara kerjanya mudah dibayangkan secara manual:

Bubble Sort Menukar pasangan elemen bersebelahan berulang kali
Selection Sort Mencari elemen terkecil lalu menukarnya ke posisi yang benar
📌
Kedua algoritma ini disebut algoritma sorting sederhana (simple sorting). Mereka mudah dipahami untuk belajar logika dasar, tapi tidak efisien untuk data yang sangat besar — itu yang akan kita buktikan di bagian Perbandingan Performa nanti.
02 — ALGORITMA #1
🫧 Bubble Sort
Disebut "bubble" (gelembung) karena elemen terbesar perlahan "naik" ke posisi paling akhir, seperti gelembung udara yang naik ke permukaan air.
🧠
Cara Kerja Bubble Sort
Bandingkan dua elemen bersebelahan, tukar jika urutannya salah
1
Bandingkan elemen ke-0 dan ke-1
Jika elemen kiri lebih besar dari elemen kanan, tukar posisinya.
2
Lanjut ke pasangan berikutnya
Geser satu posisi ke kanan, bandingkan lagi, tukar jika perlu. Ulangi sampai akhir list.
3
Satu "putaran" (pass) selesai
Setelah satu putaran penuh, elemen terbesar pasti sudah berada di posisi paling akhir.
4
Ulangi putaran berikutnya
Lakukan lagi dari awal, tapi area yang sudah pasti urut (di akhir) tidak perlu dicek lagi.
✓
Berhenti saat tidak ada pertukaran lagi
Jika dalam satu putaran tidak ada penukaran sama sekali, artinya data sudah terurut sepenuhnya.
▶️
Visualisasi Langkah demi Langkah
Klik "Langkah Berikutnya" untuk melihat proses perbandingan & penukaran secara manual
Klik "Langkah Berikutnya" untuk mulai mengurutkan data.

Kode Python — Bubble Sort
Salin kode ini ke Thonny lalu jalankan (F5) untuk mencobanya sendiri
PYTHON
# bubble_sort.py # Mengurutkan list angka dari terkecil ke terbesar def bubble_sort(data): n = len(data) for i in range(n - 1): # tandai apakah ada penukaran di putaran ini tertukar = False for j in range(0, n - i - 1): # bandingkan dua elemen bersebelahan if data[j] > data[j + 1]: # tukar posisi data[j], data[j + 1] = data[j + 1], data[j] tertukar = True # jika tidak ada penukaran, data sudah urut → berhenti lebih awal if not tertukar: break return data # --- Program utama --- angka = [64, 34, 25, 12, 22, 11, 90] print("Data sebelum diurutkan:", angka) hasil = bubble_sort(angka) print("Data setelah diurutkan :", hasil)
🟢 Coba di Thonny: Buat file baru bernama bubble_sort.py, salin kode di atas, lalu tekan F5 atau klik tombol Run untuk melihat hasilnya di Shell.
🔍
Coba ubah sendiri: Tambahkan print(f"Putaran {i+1}: {data}") di akhir loop for i agar kamu bisa melihat isi list berubah setiap putaran — bandingkan dengan visualisasi di atas!
03 — ALGORITMA #2
🎯 Selection Sort
Strategi yang lebih mirip cara manusia mengurutkan kartu: cari yang paling kecil dulu, lalu letakkan di depan.
🧠
Cara Kerja Selection Sort
Pilih (select) elemen terkecil, lalu tukar ke posisi yang tepat
1
Anggap elemen pertama sebagai "yang terkecil sementara"
Mulai dari posisi paling kiri yang belum terurut.
2
Cari elemen yang benar-benar terkecil
Bandingkan dengan semua elemen sisanya di sebelah kanan, satu per satu.
3
Tukar elemen terkecil ke posisi awal
Setelah ditemukan, tukar elemen terkecil itu dengan elemen di posisi yang sedang diproses.
4
Geser ke posisi berikutnya
Posisi pertama sudah pasti benar. Ulangi proses untuk posisi kedua, ketiga, dan seterusnya.
✓
Selesai saat hanya 1 elemen tersisa
Jika tinggal satu elemen di area belum terurut, otomatis itu sudah di posisi yang benar.
▶️
Visualisasi Langkah demi Langkah
Perhatikan bagaimana elemen "calon terkecil" (ungu) berubah saat pencarian berlangsung
Klik "Langkah Berikutnya" untuk mulai mengurutkan data.
Belum diproses Sedang dibandingkan Calon terkecil saat ini Baru ditukar Sudah pada posisi final
Perbandingan: 0
Penukaran: 0
Posisi terselesaikan: 0

Kode Python — Selection Sort
Salin kode ini ke Thonny lalu jalankan (F5) untuk mencobanya sendiri
PYTHON
# selection_sort.py # Mengurutkan list angka dari terkecil ke terbesar def selection_sort(data): n = len(data) for i in range(n - 1): # anggap posisi ke-i sebagai yang terkecil sementara idx_min = i for j in range(i + 1, n): # cari elemen yang lebih kecil dari idx_min if data[j] < data[idx_min]: idx_min = j # tukar hanya jika ditemukan yang lebih kecil if idx_min != i: data[i], data[idx_min] = data[idx_min], data[i] return data # --- Program utama --- angka = [64, 34, 25, 12, 22, 11, 90] print("Data sebelum diurutkan:", angka) hasil = selection_sort(angka) print("Data setelah diurutkan :", hasil)
🟢 Coba di Thonny: Buat file baru bernama selection_sort.py, salin kode di atas, lalu jalankan dengan F5.
🔍
Perhatikan perbedaannya: Selection Sort hanya menukar satu kali per putaran (di akhir, setelah ketemu yang terkecil), sedangkan Bubble Sort bisa menukar banyak kali dalam satu putaran. Ini salah satu alasan jumlah penukarannya berbeda jauh.
04 — PERBANDINGAN
Bubble Sort vs Selection Sort — Mana yang Lebih Baik?
Keduanya punya kompleksitas waktu yang sama secara teori, tapi berbeda dalam praktik. Yuk kita bandingkan langsung.
⚖️
Tabel Perbandingan
AspekBubble SortSelection Sort
Cara kerjaMenukar pasangan elemen bersebelahan berulang kaliMencari elemen terkecil, lalu menukarnya ke posisi yang benar
Jumlah penukaranBisa banyak (setiap kali urutan salah)Sedikit — maksimal n-1 kali (satu kali per posisi)
Jumlah perbandingann(n-1)/2 — sama dengan Selection Sortn(n-1)/2 — sama dengan Bubble Sort
Kompleksitas waktu (rata-rata)O(n²)O(n²)
Kompleksitas waktu (kasus terbaik)O(n) — jika sudah urut & pakai flag berhenti awalO(n²) — tetap mengecek semua elemen
KelebihanSederhana, bisa berhenti lebih cepat jika data sudah hampir urutJumlah penukaran data lebih sedikit (hemat operasi tukar)
KekuranganBanyak operasi tukar jika data sangat tidak urutTetap memproses semua elemen meski data sudah urut
✅
Kesimpulan singkat: Secara teori keduanya sama-sama O(n²) dan jumlah perbandingannya identik. Perbedaan nyata ada di jumlah penukaran (swap) — Selection Sort biasanya lebih hemat operasi tukar, sehingga sedikit lebih cepat pada praktiknya untuk data acak berukuran kecil-menengah.

Kode Python — UI Tkinter + Bubble Sort
Gabungan fungsi sorting dengan tampilan grafis sederhana
PYTHON
# ui_sorting.py # Aplikasi sederhana: input angka, urutkan dengan Bubble Sort import tkinter as tk from tkinter import messagebox def bubble_sort(data): n = len(data) for i in range(n - 1): for j in range(0, n - i - 1): if data[j] > data[j + 1]: data[j], data[j + 1] = data[j + 1], data[j] return data def urutkan_data(): teks = entry_input.get() try: # ubah teks "64,34,25" jadi list angka [64, 34, 25] angka = [int(x.strip()) for x in teks.split(",")] except ValueError: messagebox.showerror("Input salah", "Masukkan angka dipisah koma, contoh: 5,2,8,1") return hasil = bubble_sort(angka) label_hasil.config(text=f"Hasil terurut: {hasil}") # --- Membangun jendela utama --- window = tk.Tk() window.title("Aplikasi Bubble Sort") window.geometry("360x180") label_judul = tk.Label(window, text="Masukkan angka (pisahkan dengan koma):") label_judul.pack(pady=10) entry_input = tk.Entry(window, width=30) entry_input.pack() btn_urutkan = tk.Button(window, text="Urutkan", command=urutkan_data) btn_urutkan.pack(pady=10) label_hasil = tk.Label(window, text="Hasil terurut: -", fg="darkgreen") label_hasil.pack(pady=5) window.mainloop()

06 — STUDI KASUS
Studi Kasus: Ranking Nilai Mahasiswa
Satu kasus untuk menguji pemahamanmu, menggabungkan sorting dengan tampilan sederhana.
📋
Soal

Sebuah dosen memiliki data nilai UTS dari 6 mahasiswa berikut:

DATA
nilai = [78, 92, 65, 88, 73, 95]

Buat program Python (boleh dijalankan di terminal Thonny biasa, atau ditambahkan tampilan Tkinter seperti contoh sebelumnya) yang:

1
Mengurutkan nilai dari TERBESAR ke TERKECIL
Gunakan salah satu algoritma yang sudah dipelajari (Bubble Sort atau Selection Sort) — boleh dimodifikasi agar urutannya descending.
2
Menampilkan hasil ranking
Cetak peringkat 1 sampai 6 beserta nilainya, contoh: "Ranking 1: 95".
💡 Petunjuk ▼

Untuk mengurutkan dari terbesar ke terkecil (descending), cukup ubah tanda perbandingan di algoritma sorting kamu. Misalnya pada Bubble Sort, ubah if data[j] > data[j+1] menjadi if data[j] < data[j+1]. Setelah list terurut descending, gunakan for i, n in enumerate(nilai, start=1) untuk mencetak nomor ranking bersama nilainya.

✅ Contoh Kunci Jawaban ▼
PYTHON
# ranking_nilai.py def bubble_sort_desc(data): n = len(data) for i in range(n - 1): for j in range(0, n - i - 1): # tanda dibalik agar urut dari terbesar if data[j] < data[j + 1]: data[j], data[j + 1] = data[j + 1], data[j] return data nilai = [78, 92, 65, 88, 73, 95] nilai_urut = bubble_sort_desc(nilai) print("=== RANKING NILAI UTS ===") for peringkat, n in enumerate(nilai_urut, start=1): print(f"Ranking {peringkat}: {n}") # Output yang diharapkan: # Ranking 1: 95 # Ranking 2: 92 # Ranking 3: 88 # Ranking 4: 78 # Ranking 5: 73 # Ranking 6: 65
🟢 Coba di Thonny: Simpan sebagai ranking_nilai.py, jalankan dengan F5, lalu cocokkan hasilnya dengan output yang diharapkan di atas.
