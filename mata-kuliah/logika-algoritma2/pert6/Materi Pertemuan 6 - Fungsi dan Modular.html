Konsep Dasar

🔧 Apa Itu Fungsi?

Fungsi adalah sekumpulan perintah/instruksi yang diberi nama, yang bisa dipanggil kapan saja saat dibutuhkan.

Bayangkan fungsi seperti "mesin kecil". Kamu kasih bahan masuk (input), mesin mengolah, lalu mengeluarkan hasil (output).

🎯 Mengapa Fungsi Penting?

♻️

Reusable

Tulis sekali, gunakan berkali-kali di mana saja

🧹

Kode Lebih Rapi

Program jadi terstruktur dan mudah dibaca

🐛

Mudah Diperbaiki

Kalau ada bug, cukup perbaiki di satu tempat

👥

Tim Bisa Kolaborasi

Setiap orang bisa garap fungsi berbeda

📊 Alur Kerja Fungsi

Semua fungsi pada dasarnya bekerja dengan pola yang sama:

📥 Input
(Parameter)
→
⚙️ Proses
(Isi Fungsi)
→
📤 Output
(Return Value)
✅ Analogi sederhana: Mesin ATM — kamu masukkan PIN & jumlah uang (INPUT), ATM memproses (PROSES), kamu dapat uang keluar (OUTPUT).
3
Struktur

📐 Struktur Fungsi dalam C++

Di C++, setiap fungsi punya struktur baku yang wajib kamu pahami:

Format Umum
1tipe_return nama_fungsi(tipe parameter1, tipe parameter2) {
2 // isi fungsi di sini
3 return hasil;
4}

Sekarang kita lihat contoh nyata: fungsi penjumlahan 2 angka.

📝 Pseudocode

Pseudocode — Fungsi Penjumlahan FUNGSI tambah(a, b): hasil ← a + b KEMBALIKAN hasil AKHIR FUNGSI PROGRAM UTAMA: x ← 5 y ← 3 total ← panggil tambah(x, y) TAMPILKAN total → hasilnya: 8

💻 Kode C++

C++
1// Header
2#include <iostream>
3using namespace std;
4
5// ↓ DEFINISI FUNGSI
6int tambah(int a, int b) { // ← parameter: a dan b
7 int hasil = a + b; // ← proses
8 return hasil; // ← return value
9}
10
11// ↓ PROGRAM UTAMA
12int main() {
13 int x = 5, y = 3;
14 int total = tambah(x, y); // ← memanggil fungsi
15 cout << "Hasil: " << total; // Output: Hasil: 8
16 return 0;
17}

🔍 Penjelasan Setiap Bagian

1
int di depan nama fungsi = tipe data yang akan dikembalikan. Di sini kita kembalikan angka bulat (integer).
2
tambah = nama fungsi. Boleh apapun, tapi harus mencerminkan tugasnya. Seperti nama resep.
3
(int a, int b) = parameter, yaitu "bahan" yang dibutuhkan fungsi untuk bekerja. Di sini dua angka integer.
4
return hasil; = perintah untuk mengembalikan hasil ke pemanggil fungsi. Ini nilai "output" dari fungsi.
5
tambah(x, y) di main() = memanggil fungsi. x dan y dikirim ke dalam fungsi sebagai nilai a dan b.
4
Parameter & Return

📦 Parameter & Return Value

Dua konsep ini sering bikin bingung mahasiswa. Coba kita pahami dengan analogi yang santai:

🧃

Parameter = Bahan

Yang kamu kasih ke fungsi sebelum diproses. Seperti bahan masakan yang kamu serahkan ke juru masak.

🍽️

Return Value = Hasil

Yang dikembalikan fungsi setelah selesai bekerja. Seperti makanan jadi yang keluar dari dapur.

📌 Contoh: Fungsi Hitung Luas Persegi Panjang

luas = panjang × lebar
Pseudocode — Luas Persegi Panjang FUNGSI hitungLuas(panjang, lebar): luas ← panjang × lebar KEMBALIKAN luas ← ini return value-nya AKHIR FUNGSI PROGRAM UTAMA: p ← 8 l ← 5 hasil ← panggil hitungLuas(p, l) ← parameter: p dan l TAMPILKAN "Luas = " + hasil → Luas = 40
C++
1#include <iostream>
2using namespace std;
3
4int hitungLuas(int panjang, int lebar) {
5 int luas = panjang * lebar; // proses perkalian
6 return luas; // kirim hasil ke pemanggil
7}
8
9int main() {
10 int p = 8, l = 5;
11 int hasil = hitungLuas(p, l); // kirim p=8, l=5 ke fungsi
12 cout << "Luas = " << hasil; // Output: Luas = 40
13 return 0;
14}

🔍 Penjelasan Langkah demi Langkah

1
Di main(), kita punya variabel p = 8 dan l = 5.
2
Kita memanggil fungsi hitungLuas(p, l). Nilai p dan l dikirim ke parameter fungsi.
3
Di dalam fungsi, panjang = 8 dan lebar = 5 (parameter menerima nilai dari pemanggil).
4
Fungsi menghitung 8 × 5 = 40, disimpan di variabel lokal luas.
5
return luas mengirim nilai 40 kembali ke tempat pemanggil.
6
Nilai 40 tersimpan di hasil di dalam main(), lalu ditampilkan ke layar.
✅ Ingat: Tipe data parameter dan return value harus sesuai. Kalau fungsi return int, variabel penampungnya juga harus int.
5
Scope

🔒 Scope Variabel: Lokal vs Global

Scope adalah "wilayah berlaku" suatu variabel. Ini sering jadi sumber bug yang membingungkan!

🏫 Analogi Kampus: Bayangkan variabel seperti benda milik seseorang.
Variabel lokal = buku yang ada di dalam kelas → hanya bisa dipakai di dalam kelas itu saja.
Variabel global = mading di depan kampus → bisa dilihat semua orang dari mana saja.
Jenis Lokasi Deklarasi Bisa Diakses Di Contoh
🏠 Lokal Di dalam fungsi/blok Hanya dalam fungsi itu int x = 5; di dalam fungsi
🌐 Global Di luar semua fungsi Semua fungsi dalam file int x = 5; sebelum main()
C++ — Scope
1#include <iostream>
2using namespace std;
3
4int nilaiGlobal = 100; // ← GLOBAL: bisa diakses semua fungsi
5
6void contohFungsi() {
7 int nilaiLokal = 50; // ← LOKAL: hanya ada di sini
8 cout << nilaiGlobal; // ✅ boleh, global bisa diakses di sini
9 cout << nilaiLokal; // ✅ boleh, ini tempatnya
10}
11
12int main() {
13 cout << nilaiGlobal; // ✅ boleh
14 // cout << nilaiLokal; // ❌ ERROR! nilaiLokal tidak dikenal di sini
15 return 0;
16}
✅ Tips: Sebaiknya hindari terlalu banyak variabel global. Lebih aman dan rapi menggunakan parameter untuk mengirim data antar fungsi.

Modularisasi

🏗️ Modularisasi: Pecah Program Jadi Fungsi Kecil

Modularisasi adalah teknik memecah program besar menjadi fungsi-fungsi kecil yang masing-masing punya tugas spesifik.

🏠 Analogi Membangun Rumah: Kalau mau bangun rumah, kamu tidak menyuruh satu tukang ngerjain segalanya. Ada tukang bata, tukang listrik, tukang plumber. Masing-masing ahli di bidangnya. Hasilnya? Lebih cepat, lebih bagus, lebih mudah diperbaiki.

Program juga sama. Daripada satu fungsi main() yang isinya ratusan baris, lebih baik dibagi menjadi beberapa fungsi:

📥

inputData()

Khusus menerima input dari user

🧮

hitungData()

Khusus melakukan perhitungan

📊

tampilHasil()

Khusus menampilkan output

💡 Contoh: Program Nilai Mahasiswa (Termodular)

C++
1#include <iostream>
2using namespace std;
3
4// Modul 1: Input
5float inputNilai() {
6 float nilai;
7 cout << "Masukkan nilai: ";
8 cin >> nilai;
9 return nilai;
10}
11
12// Modul 2: Hitung rata-rata
13float hitungRata(float a, float b, float c) {
14 return (a + b + c) / 3;
15}
16
17// Modul 3: Tampilkan hasil
18void tampilHasil(float rata) {
19 cout << "Nilai Akhir: " << rata << endl;
20}
21
22// Program Utama — bersih dan ringkas!
23int main() {
24 float t = inputNilai();
25 float u = inputNilai();
26 float s = inputNilai();
27 float akhir = hitungRata(t, u, s);
28 tampilHasil(akhir);
29 return 0;
30}
✅ Lihat betapa bersihnya main()! Hanya berisi "alur cerita" program, tanpa detail teknis yang berdesakan.

Studi Kasus

📚 Studi Kasus: Nilai Akhir Mahasiswa

🔍 1. Analisis Masalah

Dosen minta program untuk menghitung nilai akhir mahasiswa berdasarkan 3 komponen penilaian:

nilai_akhir = (tugas + uts + uas) / 3

Program harus bisa dipakai berulang untuk banyak mahasiswa, dan mudah dimodifikasi kalau rumusnya berubah.

📦 2. Pembagian Fungsi

📥

inputNilai()

Terima input tugas, UTS, UAS dari user

🧮

hitungNilaiAkhir()

Hitung rata-rata dari 3 nilai

🔤

tentukanGrade()

Tentukan grade A/B/C/D/E

📊

tampilHasil()

Cetak semua hasil ke layar

📝 3. Pseudocode Lengkap

Pseudocode — Sistem Nilai Mahasiswa FUNGSI inputNilai(): INPUT tugas, uts, uas KEMBALIKAN tugas, uts, uas FUNGSI hitungNilaiAkhir(tugas, uts, uas): nilai_akhir ← (tugas + uts + uas) / 3 KEMBALIKAN nilai_akhir FUNGSI tentukanGrade(nilai): JIKA nilai >= 80 MAKA grade ← 'A' JIKA nilai >= 70 MAKA grade ← 'B' JIKA nilai >= 60 MAKA grade ← 'C' JIKA nilai >= 50 MAKA grade ← 'D' SELAINNYA grade ← 'E' KEMBALIKAN grade FUNGSI tampilHasil(nama, nilai, grade): TAMPILKAN "Nama : " + nama TAMPILKAN "Nilai Akhir: " + nilai TAMPILKAN "Grade : " + grade PROGRAM UTAMA: INPUT nama mahasiswa tugas, uts, uas ← panggil inputNilai() nilai ← panggil hitungNilaiAkhir(tugas, uts, uas) grade ← panggil tentukanGrade(nilai) panggil tampilHasil(nama, nilai, grade)

🔁 4. Penjelasan Logika Langkah demi Langkah

1
Program dimulai dari main(). Input nama mahasiswa diterima.
2
inputNilai() dipanggil — fungsi ini meminta user mengetik 3 nilai, lalu mengembalikannya.
3
Nilai tugas, UTS, UAS dikirim ke hitungNilaiAkhir() sebagai parameter → fungsi menghitung rata-rata.
4
Nilai rata-rata dikirim ke tentukanGrade() → fungsi mengembalikan karakter grade (A/B/C/D/E).
5
tampilHasil() menerima nama, nilai akhir, dan grade, lalu mencetak semua ke layar dengan rapi.

💻 5. Kode C++ Lengkap

C++
1#include <iostream>
2#include <string>
3using namespace std;
4
5// ===== FUNGSI 1: Input Nilai =====
6void inputNilai(float &tugas, float &uts, float &uas) {
7 cout << "Nilai Tugas : "; cin >> tugas;
8 cout << "Nilai UTS : "; cin >> uts;
9 cout << "Nilai UAS : "; cin >> uas;
10}
11
12// ===== FUNGSI 2: Hitung Nilai Akhir =====
13float hitungNilaiAkhir(float tugas, float uts, float uas) {
14 return (tugas + uts + uas) / 3.0;
15}
16
17// ===== FUNGSI 3: Tentukan Grade =====
18char tentukanGrade(float nilai) {
19 if (nilai >= 80) return 'A';
20 if (nilai >= 70) return 'B';
21 if (nilai >= 60) return 'C';
22 if (nilai >= 50) return 'D';
23 return 'E';
24}
25
26// ===== FUNGSI 4: Tampilkan Hasil =====
27void tampilHasil(string nama, float nilai, char grade) {
28 cout << "\n========== HASIL ==========" << endl;
29 cout << "Nama : " << nama << endl;
30 cout << "Nilai Akhir : " << nilai << endl;
31 cout << "Grade : " << grade << endl;
32 cout << "==========================" << endl;
33}
34
35// ===== PROGRAM UTAMA =====
36int main() {
37 string nama;
38 float tugas, uts, uas;
39
40 cout << "=== Program Nilai Mahasiswa ===" << endl;
41 cout << "Nama Mahasiswa: "; cin >> nama;
42
43 inputNilai(tugas, uts, uas);
44
45 float nilaiAkhir = hitungNilaiAkhir(tugas, uts, uas);
46 char grade = tentukanGrade(nilaiAkhir);
47
48 tampilHasil(nama, nilaiAkhir, grade);
49 return 0;
50}

🔬 6. Penjelasan Setiap Fungsi

F1
inputNilai() — return type void karena tidak mengembalikan nilai langsung. Gunakan referensi (&) agar nilai bisa diubah langsung dari luar fungsi.
F2
hitungNilaiAkhir() — menerima 3 float, langsung menghitung dan me-return hasilnya. Singkat, padat, satu tugas.
F3
tentukanGrade() — menerima nilai float, mengembalikan char. Gunakan if berjenjang — cukup return langsung tanpa else.
F4
tampilHasil() — hanya bertugas menampilkan. Return void karena tugasnya output, bukan menghitung.
M
main() — bersih! Hanya mengkoordinasikan pemanggilan fungsi. Seperti manager yang mendelegasikan tugas ke timnya.

Latihan

✏️ Latihan Mahasiswa

Coba kerjakan dulu tanpa langsung lihat jawaban. Proses berpikir lebih penting dari hasil! 💪

⭐ Mudah

Soal 1: Fungsi Penjumlahan Tiga Angka

Deskripsi: Buat sebuah fungsi bernama jumlahTiga yang menerima 3 bilangan bulat sebagai parameter, lalu mengembalikan hasil penjumlahannya. Panggil fungsi tersebut dari main() dan tampilkan hasilnya.

Contoh: Input 10, 20, 30 → Output: Jumlah = 60

💡 Petunjuk Logika:
1. Tipe return apa yang cocok? (Jawab: int)
2. Berapa parameter yang dibutuhkan? (Jawab: 3 int)
3. Di dalam fungsi, tambahkan ketiganya, simpan ke variabel, lalu return.
4. Di main(), panggil fungsi dan simpan hasilnya ke variabel.
⭐⭐ Sedang

Soal 2: Fungsi Cek Genap atau Ganjil

Deskripsi: Buat fungsi cekGenap yang menerima 1 bilangan bulat. Fungsi mengembalikan nilai true jika bilangan genap, dan false jika ganjil. Di main(), tampilkan "Genap" atau "Ganjil" berdasarkan hasil fungsi.

Contoh: Input 7 → Output: 7 adalah bilangan Ganjil

💡 Petunjuk Logika:
1. Tipe return yang cocok: bool (true/false)
2. Gunakan operator modulo (%): bilangan genap jika angka % 2 == 0
3. Di main(), gunakan if-else untuk mencetak "Genap" atau "Ganjil" berdasarkan nilai bool.
4. Cobalah dengan beberapa angka berbeda untuk memastikan hasilnya benar.
⭐⭐⭐ Agak Sulit

Soal 3: Fungsi Hitung Diskon

Deskripsi: Sebuah toko memberi diskon berdasarkan total belanja: jika di atas Rp 500.000 → diskon 20%; jika di atas Rp 200.000 → diskon 10%; selainnya → tidak ada diskon. Buat fungsi hitungDiskon yang menerima total belanja dan mengembalikan harga setelah diskon. Tampilkan juga besaran diskon yang diterima.

Contoh: Input 600000 → Diskon: Rp 120.000 → Bayar: Rp 480.000

💡 Petunjuk Logika:
1. Buat 2 fungsi: persenDiskon(harga) untuk dapat persen diskon, dan hitungDiskon(harga) untuk hitung harga akhir.
2. Gunakan if-else if-else untuk menentukan persen diskon.
3. Rumus: diskon = harga * persen / 100, lalu harga_akhir = harga - diskon
4. Di main(), tampilkan harga awal, jumlah diskon, dan harga yang harus dibayar.

Ringkasan

📌 Ringkasan Materi Pertemuan 5

🔧

Fungsi

Kumpulan perintah yang diberi nama. Tulis sekali, panggil berkali-kali.

📥

Parameter

Input/bahan yang dikirim ke dalam fungsi agar bisa diproses.

📤

Return Value

Nilai yang dikembalikan fungsi setelah selesai bekerja.

🔒

Scope

Batas wilayah berlaku variabel. Lokal hanya dalam fungsinya sendiri.

🧩

Modularisasi

Memecah program besar menjadi fungsi-fungsi kecil yang spesifik.

🎯

void vs return

void jika tidak perlu kembalikan nilai. int/float jika ada output.

🚀 Key Takeaway

Fungsi bukan sekadar sintaks — ini adalah cara berpikir. Setiap kali kamu punya tugas yang berulang atau punya tanggung jawab spesifik, pertimbangkan untuk menjadikannya fungsi tersendiri.

Program yang baik dibaca seperti buku cerita — main() yang bersih menceritakan alur umum, sedangkan fungsi-fungsi lain menyimpan detail implementasinya.
