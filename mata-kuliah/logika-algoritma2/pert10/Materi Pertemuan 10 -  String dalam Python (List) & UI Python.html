String dalam Python

Belajar mengolah data teks — dari karakter, slicing, pencarian, hingga method string yang sering dipakai.

🔤 Karakter & Indeks ✂️ Slicing 🔍 Pencarian 🔗 Gabung 🔁 Loop
01 — Konsep Dasar

String adalah kumpulan karakter yang ditulis di antara tanda kutip. Bayangkan string seperti array — tapi khusus untuk teks.

💡
Ingat dari materi sebelumnya: List = kumpulan data apa saja. String = kumpulan karakter (huruf, angka, simbol).

Setiap karakter punya indeks mulai dari 0:

B
0
u
1
d
2
i
3
PYTHON
# Penulisan string — bisa kutip satu atau dua nama = "Budi" kota = 'Jakarta' salam = "Selamat pagi!" # Akses karakter per indeks print(nama[0]) # B print(nama[-1]) # i (dari belakang) print(type(nama)) # <class 'str'>
02 — Panjang String

Fungsi len() menghitung jumlah karakter dalam string, termasuk spasi.

PYTHON
nama = "Budi Santoso" print(len(nama)) # 12 (termasuk spasi) # Cek apakah panjang minimal 5 if len(nama) >= 5: print("Nama cukup panjang")

04 — Pencarian dalam String

Cari apakah suatu kata/karakter ada di dalam string menggunakan in atau .find().

05 — Slicing

Slicing mengambil sebagian karakter dari string. Sintaks: string[start:end] — ambil dari indeks start sampai sebelum end.

⚠️
Ingat: indeks end tidak ikut terambil! "Python"[0:3] → "Pyt" (bukan "Pyth")
PYTHON
s = "Pemrograman" print(s[0:3]) # Pem print(s[4:]) # rograman (sampai akhir) print(s[:5]) # Pemro (dari awal) print(s[::-1]) # namargormeP (balik) print(s[0:10:2]) # Pmgmn (setiap 2 langkah)

06 — Method String

Python menyediakan banyak method bawaan untuk memanipulasi string:

Ubah Huruf: upper(), lower(), title(), capitalize() ▼
PYTHON
s = "pemrograman dasar" print(s.upper()) # PEMROGRAMAN DASAR print(s.lower()) # pemrograman dasar print(s.title()) # Pemrograman Dasar print(s.capitalize()) # Pemrograman dasar
strip(), replace(), split() ▼
PYTHON
s = " Halo, Budi! " print(s.strip()) # "Halo, Budi!" — hapus spasi tepi print(s.replace("Budi", "Sari")) # " Halo, Sari! " kata = "nasi,ayam,sayur" print(kata.split(",")) # ['nasi', 'ayam', 'sayur'] # join — kebalikan split daftar = ["nasi", "ayam", "sayur"] print(", ".join(daftar)) # nasi, ayam, sayur
startswith(), endswith(), isdigit(), isalpha() ▼
PYTHON
email = "budi@email.com" print(email.endswith(".com")) # True print(email.startswith("budi")) # True angka = "12345" print(angka.isdigit()) # True print(angka.isalpha()) # False (semua huruf?) teks = "Python" print(teks.isalpha()) # True

UI Sederhana dengan Tkinter

Buat antarmuka grafis (GUI) menggunakan library bawaan Python — widget, layout, event, hingga template siap pakai.

📦 Bawaan Python 🖥️ Cross-Platform 🎓 Mudah Dipelajari
01 — Pengenalan

Tkinter adalah library GUI (Graphical User Interface) bawaan Python. Tidak perlu install — langsung import dan pakai. Jalan di Windows, macOS, dan Linux.

📦

Bawaan Python

Tidak perlu pip install apapun.

🖥️

Cross-Platform

Jalan di Windows, macOS, Linux.

🎓

Cocok Pemula

Sintaks sederhana, dokumentasi lengkap.

⚡

Cepat Prototipe

Dari nol ke UI yang berjalan dengan beberapa baris.

💡
Kapan pakai Tkinter? Kalkulator, form input, tools sederhana, proyek belajar. Untuk UI kompleks atau mobile, pertimbangkan PyQt5 atau Kivy.
02 — Program Pertama

Verifikasi Tkinter sudah ada dengan: python -m tkinter. Jika muncul jendela kecil, siap dipakai.

PYTHON
import tkinter as tk # 1. Buat jendela utama root = tk.Tk() # 2. Atur properti jendela root.title("Aplikasi Pertamaku") root.geometry("400x300") # lebar x tinggi (pixel) root.configure(bg="#f0f4ff") # 3. Tambah label label = tk.Label(root, text="Halo, Dunia!", font=("Segoe UI", 16)) label.pack(pady=40) # 4. Jalankan — wajib ada di paling akhir! root.mainloop()
🚨
mainloop() WAJIB ada di paling akhir. Fungsi ini yang membuat jendela tetap terbuka dan merespons interaksi pengguna.

04 — Sistem Layout

Tkinter punya 3 geometry manager untuk mengatur posisi widget. Jangan campur dalam satu container.

📦

pack()

Susun widget berurutan atas-bawah atau kiri-kanan. Paling mudah.

📐

grid()

Susun dalam baris dan kolom seperti tabel. Cocok untuk form.

📍

place()

Posisi tepat dengan koordinat x, y. Paling fleksibel tapi manual.

Contoh pack() — susun vertikal ▼
PYTHON
tk.Label(root, text="Nama:").pack(anchor="w", padx=20) tk.Entry(root).pack(fill="x", padx=20, pady=(0,10)) tk.Button(root, text="Kirim").pack()
Contoh grid() — form dengan label + entry ▼
PYTHON
# grid(row=baris, column=kolom) tk.Label(root, text="Nama:").grid(row=0, column=0, padx=10, pady=8, sticky="e") tk.Entry(root).grid(row=0, column=1, padx=10) tk.Label(root, text="Usia:").grid(row=1, column=0, padx=10, pady=8, sticky="e") tk.Entry(root).grid(row=1, column=1, padx=10)
05 — Event & Binding

Event adalah kejadian yang dipantau — misalnya klik mouse, tekan tombol keyboard, atau gerakan kursor.

PYTHON
# Cara 1: command= pada Button (paling umum) def klik_tombol(): label.config(text="Tombol diklik!") btn = tk.Button(root, text="Klik", command=klik_tombol) # Cara 2: bind() — untuk event apapun entry.bind("<Return>", lambda e: klik_tombol()) # tekan Enter root.bind("<Escape>", lambda e: root.quit()) # tekan Esc = keluar # Cara 3: StringVar — update otomatis var = tk.StringVar() var.trace("w", lambda *a: label.config(text=var.get())) entry = tk.Entry(root, textvariable=var)
⚠️
Hindari operasi berat (download file, query besar) di dalam event handler. Ini akan membekukan UI. Gunakan threading untuk operasi lambat.
06 — Template UI Lengkap

Template berikut bisa langsung dipakai — cukup ganti fungsi proses_teks() sesuai kebutuhan.

Aplikasi Pengolah Teks
Masukkan teks:
Hasil akan muncul di sini...
PYTHON — TEMPLATE TKINTER
import tkinter as tk # ── GANTI FUNGSI INI sesuai kebutuhan ────────── def proses_teks(teks): return teks.upper() # ubah jadi huruf besar # ────────────────────────────────────────────── def klik_proses(): teks = entry.get().strip() if not teks: label_hasil.config(text="⚠️ Teks masih kosong!", fg="#E03131") return hasil = proses_teks(teks) label_hasil.config(text=hasil, fg="#0CA678") entry.delete(0, "end") # Setup jendela root = tk.Tk() root.title("Pengolah Teks") root.geometry("400x220") root.configure(bg="#F5F7FF") root.resizable(False, False) # Widget tk.Label(root, text="Masukkan teks:", font=("Segoe UI", 10), bg="#F5F7FF" ).pack(anchor="w", padx=20, pady=(20,4)) entry = tk.Entry(root, font=("Segoe UI", 12), relief="solid", bd=1) entry.pack(fill="x", padx=20, ipady=5) entry.bind("<Return>", lambda e: klik_proses()) btn = tk.Button(root, text="🔄 Proses", command=klik_proses, font=("Segoe UI", 11), bg="#3B5BDB", fg="white", relief="flat", padx=20, pady=6, cursor="hand2") btn.pack(pady=12) label_hasil = tk.Label(root, text="Hasil muncul di sini...", font=("Segoe UI", 13, "bold"), bg="#F5F7FF", fg="#6B7280") label_hasil.pack(pady=4) root.mainloop()
✅
Cara kustomisasi: Cukup ganti isi fungsi proses_teks(teks). Bagian lainnya (UI, event, layout) tidak perlu diubah!

PYTHON
def proses_teks(teks): try: c = float(teks) f = c * 9/5 + 32 return f"{c}°C = {f:.2f}°F" except: return "⚠️ Masukkan angka yang valid"

Soal 1 — Format Nama
Minta input nama lengkap dari user. Tampilkan nama dalam format Title Case, panjangnya, dan inisialnya (huruf pertama tiap kata). Contoh: "budi santoso" → "Budi Santoso", panjang: 12, inisial: "B.S"
nama = input("Nama lengkap: ") title = nama.title() panjang = len(nama) inisial = ".".join(w[0].upper() for w in nama.split()) print(f"Title Case : {title}") print(f"Panjang : {panjang}") print(f"Inisial : {inisial}")
Soal 2 — Validasi Username
Minta input username. Validasi: panjang minimal 5 karakter, tidak boleh ada spasi, tidak boleh mengandung karakter selain huruf dan angka.
username = input("Masukkan username: ") if len(username) < 5: print(f"❌ Terlalu pendek! ({len(username)} karakter, min 5)") elif " " in username: print("❌ Tidak boleh ada spasi!") elif not username.isalnum(): print("❌ Hanya huruf dan angka yang boleh!") else: print(f"✅ Username '{username}' valid! ({len(username)} karakter)")

kalimat = input("Masukkan kalimat: ").lower() vokal = "aiueo" jml_vokal = 0 jml_konsonan = 0 for h in kalimat: if h.isalpha(): if h in vokal: jml_vokal += 1 else: jml_konsonan += 1 print(f"Vokal : {jml_vokal}") print(f"Konsonan : {jml_konsonan}")
🖥️ Tkinter
Soal 4 — Kalkulator BMI
Buat UI Tkinter dengan 2 Entry (berat dan tinggi badan) dan 1 Button. Ketika diklik, tampilkan nilai BMI dan kategorinya (Kurus < 18.5 / Normal 18.5–24.9 / Gemuk ≥ 25).
import tkinter as tk def hitung_bmi(): try: berat = float(entry_berat.get()) tinggi = float(entry_tinggi.get()) / 100 # cm ke meter bmi = berat / (tinggi ** 2) if bmi < 18.5: kategori = "Kurus" elif bmi < 25: kategori = "Normal" else: kategori = "Gemuk" label_hasil.config(text=f"BMI: {bmi:.1f} — {kategori}", fg="#0CA678") except: label_hasil.config(text="⚠️ Masukkan angka yang valid", fg="#E03131") root = tk.Tk() root.title("Kalkulator BMI") root.geometry("360x200") root.configure(bg="#F5F7FF") tk.Label(root, text="Berat (kg):", bg="#F5F7FF").grid(row=0,column=0,padx=16,pady=8,sticky="e") entry_berat = tk.Entry(root, relief="solid", bd=1) entry_berat.grid(row=0, column=1, padx=16) tk.Label(root, text="Tinggi (cm):", bg="#F5F7FF").grid(row=1,column=0,padx=16,pady=8,sticky="e") entry_tinggi = tk.Entry(root, relief="solid", bd=1) entry_tinggi.grid(row=1, column=1, padx=16) tk.Button(root, text="Hitung BMI", command=hitung_bmi, bg="#3B5BDB", fg="white", relief="flat", padx=16).grid(row=2,columnspan=2,pady=10) label_hasil = tk.Label(root, text="", bg="#F5F7FF", font=("Segoe UI",12,"bold")) label_hasil.grid(row=3, columnspan=2) root.mainloop()
Soal 5 — Password Checker (Tantangan!)
Buat UI dengan satu Entry untuk password. Secara real-time (saat user mengetik), tampilkan indikator kekuatan: Lemah (panjang <6), Sedang (ada huruf besar atau angka), Kuat (panjang ≥8, ada huruf besar DAN angka).
import tkinter as tk def cek_password(*args): pw = var_pw.get() punya_besar = any(c.isupper() for c in pw) punya_angka = any(c.isdigit() for c in pw) if len(pw) == 0: lbl.config(text="Ketik password...", fg="#6B7280") elif len(pw) < 6: lbl.config(text="🔴 Lemah", fg="#E03131") elif len(pw) >= 8 and punya_besar and punya_angka: lbl.config(text="🟢 Kuat", fg="#0CA678") else: lbl.config(text="🟡 Sedang", fg="#F59F00") root = tk.Tk() root.title("Password Checker") root.geometry("340x160") root.configure(bg="#F5F7FF") tk.Label(root, text="Password:", bg="#F5F7FF", font=("Segoe UI",10)).pack(anchor="w",padx=20,pady=(20,4)) var_pw = tk.StringVar() var_pw.trace("w", cek_password) tk.Entry(root, textvariable=var_pw, show="*", font=("Segoe UI",13), relief="solid", bd=1).pack(fill="x", padx=20, ipady=5) lbl = tk.Label(root, text="Ketik password...", bg="#F5F7FF", font=("Segoe UI",13,"bold"), fg="#6B7280") lbl.pack(pady=12) root.mainloop()
