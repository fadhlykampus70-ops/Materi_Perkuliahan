Recall C++ 💾

Kita recall dulu apa yang sudah kalian pelajari 7 pertemuan lalu. Bukan untuk dihafal ulang — tapi untuk dibandingkan dengan Python nanti.

🧱
Dasar C++
  • Harus include library & deklarasi tipe
  • Program dimulai dari main()
  • Setiap baris diakhiri titik koma
#include <iostream> using namespace std; int main() { cout << "Hello!"; return 0; }
🔀
Percabangan
  • Menggunakan if / else if / else
  • Blok kode dibungkus {}
if (nilai >= 80) { cout << "A"; } else { cout << "B"; }
🔄
Perulangan
  • for, while, do-while
  • Ada inisialisasi, kondisi, increment
for (int i=1; i<=5; i++) { cout << i << endl; }
⚙️
Fungsi
  • Harus dideklarasikan tipe return-nya
  • Bisa dipanggil berulang kali
int tambah(int a, int b) { return a + b; }
🔁
Rekursi
  • Fungsi memanggil dirinya sendiri
  • Wajib ada base case (kondisi berhenti)
int faktorial(int n) { if (n == 0) return 1; return n * faktorial(n-1); }

Transisi ke Python 🐍

Coba kita lihat perbedaan-perbedaannya satu per satu. Ini sebenarnya tidak banyak kok — yang berubah hanya cara penulisannya.

Konsep ⚙️ C++ 🐍 Python
Output cout << "teks"; print("teks")
Input cin >> variabel; variabel = input()
Blok kode { ... } indentasi (spasi 4)
Tipe data int x = 5; x = 5
Komentar // komentar # komentar
Titik koma WAJIB di akhir baris TIDAK PERLU
Compile g++ file.cpp → jalankan python file.py (langsung!)
Perulangan for for(int i=0; i<5; i++) for i in range(5):
💡 Intinya: Python lebih "santai" dalam penulisan. Tidak perlu titik koma, tidak perlu deklarasi tipe, tidak perlu compile dulu. Bedanya cuma di sini — logika if, for, fungsi semuanya sama!

Materi Utama

Dasar Python 🐍

Oke, sekarang kita mulai coding Python! Santai dulu — kita bahas satu per satu, pelan-pelan.

A Variabel & Tipe Data

Ini sebenarnya sama seperti di C++, tapi... lebih simpel. Bedanya cuma di sini: Python tidak perlu deklarasi tipe data. Langsung assign saja.

Python 
# C++ → int nama = "Budi";  ← Salah! String di int
# C++ → string nama = "Budi";  ← Harus tulis tipe dulu

# Python → langsung saja:
nama = "Budi"        # otomatis tipe string
usia = 20          # otomatis tipe integer
nilai = 85.5       # otomatis tipe float
lulus = True       # otomatis tipe boolean

# Cek tipe data pakai:
print(type(nama))   # output: <class 'str'>
💡 Python itu "pintar" — dia bisa tebak sendiri tipe datanya. Kamu tidak perlu tulis int, string, float sebelum nama variabel.
B Output dengan print()

Ganti cout << dengan print(). Sesimpel itu.

Python 
nama = "Budi"
usia = 20

print("Hello, World!")          # Hello, World!
print("Nama:", nama)             # Nama: Budi
print(f"Nama: {nama}")            # f-string — cara keren!
print(f"Usia: {usia} tahun")      # Usia: 20 tahun
💡 f-string adalah cara praktis menampilkan variabel di dalam teks. Awali string dengan f dan taruh variabel dalam {}. Ini lebih rapi dari cout << "Nama: " << nama; kan?
C Input dari Pengguna

Ganti cin >> dengan input(). Tapi ada satu catatan penting...

Python 
nama = input("Masukkan nama: ")       # hasil: string

# ⚠️ input() SELALU menghasilkan tipe STRING!
# Kalau mau angka, harus dikonversi dulu:

usia = int(input("Masukkan usia: "))   # konversi ke integer
nilai = float(input("Masukkan nilai: ")) # konversi ke float
⚠️ Ini jebakan paling umum! Kalau kamu lupa konversi, lalu mau hitung usia + 1, Python akan error karena tidak bisa tambah string dengan angka. Selalu ingat: input() = string, butuh int() atau float() untuk angka.
D Operator Aritmatika

Sebagian besar sama dengan C++. Yang beda ada 3 — yang ini wajib diperhatikan!

Python 
a, b = 10, 3

print(a + b)   # 13  → Sama seperti C++
print(a - b)   # 7   → Sama seperti C++
print(a * b)   # 30  → Sama seperti C++

print(a / b)   # 3.333... → BEDA! Di C++ int/int = int, Python hasilnya float
print(a // b)  # 3  → Pembagian bulat (seperti int/int di C++)
print(a % b)   # 1  → Modulo, sama seperti C++
print(a ** b)  # 1000 → Pangkat! Di C++ pakai pow(a,b)
💡 Yang perlu diingat: / = bagi biasa (hasilnya desimal), // = bagi bulat, ** = pangkat. Tiga operator ini tidak ada di C++.
E Percabangan (if / elif / else)

Logikanya SAMA dengan C++. Yang beda: else if jadi elif, tidak ada kurung kurawal, dan wajib pakai titik dua : di akhir kondisi.

⚙️ C++ (dulu)
C++ 
if (nilai >= 80) {
  cout << "A";
} else if (nilai >= 70) {
  cout << "B";
} else {
  cout << "C";
}
🐍 Python (sekarang)
Python 
if nilai >= 80:
    print("A")
elif nilai >= 70:
    print("B")
else:
    print("C")
💡 Perhatikan: tidak ada () di kondisi, tidak ada {}, dan WAJIB indentasi 4 spasi untuk blok kode. Indentasi ini adalah pengganti kurung kurawal!
F Perulangan (for & while)

For loop di Python jauh lebih ringkas. Tidak perlu inisialisasi, kondisi, dan increment secara terpisah.

Python 
# range(start, stop, step)
# stop TIDAK termasuk! range(1, 6) = 1, 2, 3, 4, 5

for i in range(1, 6):
    print(i)          # output: 1 2 3 4 5

# Hitung mundur
for i in range(5, 0, -1):
    print(i)          # output: 5 4 3 2 1

# While loop — sama konsepnya
i = 1
while i <= 5:
    print(i)
    i += 1            # tidak ada i++ di Python!
💡 range(1, 6) artinya dari 1 sampai 5 (angka 6 TIDAK termasuk). Ini sering bikin bingung pertama kali — tapi cepat hafal! Dan ingat: tidak ada i++ di Python, pakainya i += 1.

Soal Latihan 📝

Coba kerjakan di Google Colab! Klik "Tampilkan Contoh Jawaban" kalau sudah coba sendiri dulu ya.

1
Kalkulator Sederhana — Buat program yang menerima 2 angka dan tampilkan hasil +, -, *, /
Contoh Jawaban 
a = float(input("Masukkan angka pertama: "))
b = float(input("Masukkan angka kedua: "))

print(f"Penjumlahan  : {a + b}")
print(f"Pengurangan  : {a - b}")
print(f"Perkalian    : {a * b}")

if b != 0:
    print(f"Pembagian    : {a / b}")
else:
    print("Tidak bisa dibagi nol!")
2
Ganjil / Genap — Cek apakah bilangan yang diinput ganjil atau genap
Contoh Jawaban 
angka = int(input("Masukkan angka: "))

if angka % 2 == 0:
    print(f"{angka} adalah bilangan GENAP")
else:
    print(f"{angka} adalah bilangan GANJIL")
3
Hitung Mundur — Tampilkan hitungan mundur dari N sampai 1, lalu "Selesai!"
Contoh Jawaban 
n = int(input("Hitung mundur dari: "))

for i in range(n, 0, -1):
    print(i)

print("Selesai! 🎉")
4
Konversi Suhu — Ubah Celsius ke Fahrenheit: F = (C × 9/5) + 32
Contoh Jawaban 
celsius = float(input("Masukkan suhu Celsius: "))

fahrenheit = (celsius * 9/5) + 32

print(f"{celsius}°C = {fahrenheit}°F")
5
FizzBuzz — 1 sampai 30: FizzBuzz (÷15), Fizz (÷3), Buzz (÷5), angka (lainnya)
Contoh Jawaban 
for i in range(1, 31):
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
