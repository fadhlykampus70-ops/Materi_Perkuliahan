01 — KONSEP DASAR
Apa itu Pencarian Data (Searching)?
Mencari adalah salah satu operasi paling sering dilakukan pada data. Memahami cara kerjanya penting agar program kamu bisa menemukan data dengan cepat dan efisien.
🔍
Definisi Sederhana
Menemukan posisi sebuah nilai dalam kumpulan data

Searching (pencarian) adalah proses menemukan apakah sebuah nilai ada di dalam kumpulan data, dan jika ada — di posisi (indeks) mana nilai tersebut berada.

💡
Contoh sehari-hari: mencari nama mahasiswa di daftar absensi, mencari nomor kontak di phonebook, atau mencari produk di toko online menggunakan kolom pencarian.
🔗
Koneksi dengan Pertemuan 12 — Sorting

Di P12 kita sudah belajar mengurutkan data (Bubble Sort & Selection Sort). Ternyata, data yang sudah terurut bisa dicari jauh lebih cepat! Inilah alasan kenapa sorting dan searching sering dipelajari berdampingan — keduanya saling melengkapi. Kita akan lihat buktinya di bagian Binary Search nanti.

📌
Dua Algoritma yang Kita Bahas
Linear Search
Memeriksa data satu per satu dari awal sampai ketemu atau habis. Bisa dipakai pada data acak maupun terurut.
Binary Search
Memotong area pencarian menjadi separuh setiap langkah. Jauh lebih cepat, tapi hanya bisa pada data yang sudah terurut.
⚡
Gambaran Perbedaan Kecepatan

Bayangkan kamu mencari angka 512 di antara 1.000 angka yang sudah terurut:

Linear
≤ 512 langkah
Binary
≤ 10 langkah
Binary Search butuh paling banyak log₂(1000) ≈ 10 langkah!
02 — ALGORITMA #1
🔎 Linear Search (Pencarian Linier)
Cara paling sederhana: periksa setiap elemen satu per satu dari kiri ke kanan sampai ditemukan atau semua elemen sudah diperiksa.
🧠
Cara Kerja Linear Search
Seperti mencari kunci di antara banyak kunci, satu per satu
1
Mulai dari elemen pertama (indeks 0)
Bandingkan elemen tersebut dengan nilai yang dicari (target).
2
Jika cocok → selesai, kembalikan indeksnya
Data ditemukan pada posisi tersebut.
3
Jika tidak cocok → lanjut ke elemen berikutnya
Geser satu posisi ke kanan, bandingkan lagi.
✗
Jika sudah sampai akhir dan tidak ketemu → kembalikan -1
Nilai -1 adalah konvensi umum untuk menandakan "tidak ditemukan".
▶️

Masukkan angka yang dicari lalu klik "Langkah Berikutnya".

Kode Python — Linear Search
Salin ke Thonny, jalankan dengan F5
PYTHON — linear_search.py
# linear_search.py # Mencari nilai target dalam sebuah list menggunakan Linear Search def linear_search(data, target): # periksa setiap elemen satu per satu for i in range(len(data)): print(f" Langkah {i+1}: periksa indeks {i} → nilai {data[i]}") if data[i] == target: return i # kembalikan indeks jika ditemukan return -1 # kembalikan -1 jika tidak ditemukan # --- Program utama --- data = [15, 42, 8, 37, 91, 26, 55, 73] target = int(input("Angka yang dicari: ")) print(f"\nMencari {target} di: {data}") hasil = linear_search(data, target) if hasil != -1: print(f"\n✅ Ditemukan! {target} ada di indeks {hasil}") else: print(f"\n❌ Tidak ditemukan. {target} tidak ada dalam data.")
🟢 Coba di Thonny: Simpan sebagai linear_search.py lalu tekan F5. Coba masukkan angka yang ada (misal 37) dan yang tidak ada (misal 99). Perhatikan berapa banyak langkah yang diperlukan!
🔍
Kompleksitas waktu: O(n) — semakin banyak data, semakin banyak langkah yang dibutuhkan secara linear. Kasus terbaik: target ada di indeks 0 (1 langkah). Kasus terburuk: target tidak ada atau ada di akhir (n langkah).
03 — ALGORITMA #2
⚡ Binary Search (Pencarian Biner)
Seperti mencari kata di kamus — kamu buka halaman tengah, putuskan apakah kata yang dicari ada di separuh kiri atau kanan, lalu ulangi. Setiap langkah membuang separuh kemungkinan.
⚠️
Syarat mutlak: Binary Search hanya bisa digunakan pada data yang sudah terurut! Inilah mengapa kita belajar Sorting di P12 — tanpa data yang terurut, Binary Search tidak bisa bekerja dengan benar. Pada visualisasi di bawah, data akan diurutkan terlebih dahulu secara otomatis.
🧠
Cara Kerja Binary Search
Tiga pointer: low (kiri), high (kanan), mid (tengah)
1
Tentukan batas kiri (low = 0) dan kanan (high = n-1)
Area pencarian awal adalah seluruh list.
2
Hitung posisi tengah: mid = (low + high) // 2
Elemen di posisi mid adalah kandidat pertama yang diperiksa.
3
Bandingkan data[mid] dengan target
Ada 3 kemungkinan:
• data[mid] == target → ditemukan! Selesai.
• data[mid] < target → target pasti di separuh KANAN → geser low = mid + 1
• data[mid] > target → target pasti di separuh KIRI → geser high = mid - 1
4
Ulangi dari langkah 2 dengan area pencarian yang sudah menyempit
Setiap iterasi membuang setengah dari area yang tersisa.
✗
Berhenti jika low > high → data tidak ditemukan
Area pencarian sudah habis, nilai tidak ada dalam list.
▶️

Kode Python — Binary Search
Salin ke Thonny, jalankan dengan F5
PYTHON — binary_search.py
# binary_search.py # Mencari nilai target menggunakan Binary Search # SYARAT: data harus sudah terurut dari kecil ke besar! def binary_search(data, target): low = 0 high = len(data) - 1 iterasi = 0 while low <= high: iterasi += 1 mid = (low + high) // 2 print(f" Iterasi {iterasi}: low={low} mid={mid} high={high} → cek data[{mid}]={data[mid]}") if data[mid] == target: return mid, iterasi # ditemukan elif data[mid] < target: low = mid + 1 # target di separuh kanan else: high = mid - 1 # target di separuh kiri return -1, iterasi # tidak ditemukan # --- Program utama --- data_asli = [42, 8, 91, 15, 37, 26, 55, 73] # WAJIB diurutkan dulu sebelum Binary Search! data_urut = sorted(data_asli) print(f"Data asli : {data_asli}") print(f"Data terurut: {data_urut}\n") target = int(input("Angka yang dicari: ")) print(f"\nMencari {target} di data terurut:") hasil, iterasi = binary_search(data_urut, target) if hasil != -1: print(f"\n✅ Ditemukan! {target} ada di indeks {hasil} (setelah diurutkan)") else: print(f"\n❌ Tidak ditemukan.") print(f" Total iterasi: {iterasi}")
🟢 Coba di Thonny: Simpan sebagai binary_search.py lalu tekan F5. Perhatikan berapa sedikit iterasi yang dibutuhkan dibanding Linear Search untuk data yang sama!
✅
Fungsi sorted() bawaan Python memudahkan kita mengurutkan data tanpa harus menulis ulang Bubble Sort. Hasilnya sama — data terurut ascending — siap dipakai oleh Binary Search.
🔍
Kompleksitas waktu: O(log n) — setiap langkah memotong area pencarian menjadi setengah. Untuk 1.000 data: maksimal 10 langkah. Untuk 1.000.000 data: maksimal 20 langkah!
04 — PERBANDINGAN
Linear Search vs Binary Search — Kapan Pakai yang Mana?
⚖️
Tabel Perbandingan Lengkap
AspekLinear SearchBinary Search
Cara kerjaPeriksa satu per satu dari awalPotong area pencarian jadi dua setiap langkah
Syarat dataTidak ada syarat — data acak pun bisaData wajib sudah terurut
KompleksitasO(n) — berbanding lurus jumlah dataO(log n) — jauh lebih cepat
Kasus terbaikO(1) — target ada di indeks 0O(1) — target tepat di posisi mid
Kasus terburukO(n) — target di akhir atau tidak adaO(log n) — target tidak ada
1.000 dataMaks. 1.000 langkahMaks. 10 langkah
1.000.000 dataMaks. 1.000.000 langkahMaks. 20 langkah
KelebihanSederhana, bekerja pada semua jenis dataSangat cepat untuk data besar yang terurut
KekuranganLambat untuk data besarHarus sorting dulu (ada biaya waktu untuk sorting)
Gunakan saatData kecil, atau data tidak terurut dan hanya dicari sekaliData besar, data sudah terurut, atau pencarian dilakukan berulang kali
📌
Kesimpulan penting: Jika kamu hanya mencari sekali dalam data kecil yang belum terurut, Linear Search cukup. Tapi jika pencarian dilakukan berkali-kali pada data besar, lebih hemat untuk mengurutkan datanya sekali di awal, lalu gunakan Binary Search setiap kali mencari.
05 — PENERAPAN UI
Menerapkan Searching di UI Tkinter
Melanjutkan dari materi UI sebelumnya — sekarang kita buat aplikasi pencarian sederhana dengan tampilan grafis menggunakan Tkinter.
🖼️
Rancangan Aplikasi
Input data + angka yang dicari → pilih metode → tampilkan hasil & jumlah langkah
1
Entry untuk input data dan angka yang dicari
Pengguna mengetik data (dipisah koma) dan angka target.
2
Dua tombol: "Linear Search" dan "Binary Search"
Memudahkan perbandingan langsung antara kedua metode.
3
Label hasil menampilkan status, indeks, dan jumlah langkah
Pengguna bisa langsung melihat perbedaan efisiensi kedua algoritma.
🐍
Kode Python — UI Tkinter + Linear & Binary Search
Salin ke Thonny, jalankan dengan F5
PYTHON — ui_searching.py
# ui_searching.py # Aplikasi pencarian data dengan tampilan Tkinter # Membandingkan Linear Search dan Binary Search secara langsung import tkinter as tk from tkinter import messagebox def linear_search(data, target): for i in range(len(data)): if data[i] == target: return i, i + 1 # (indeks, jumlah_langkah) return -1, len(data) def binary_search(data, target): low, high, langkah = 0, len(data) - 1, 0 while low <= high: langkah += 1 mid = (low + high) // 2 if data[mid] == target: return mid, langkah elif data[mid] < target: low = mid + 1 else: high = mid - 1 return -1, langkah def parse_input(): try: data = [int(x.strip()) for x in entry_data.get().split(",")] target = int(entry_target.get()) return data, target except ValueError: messagebox.showerror("Input salah", "Pastikan data berupa angka dipisah koma dan target berupa angka.") return None, None def jalankan_linear(): data, target = parse_input() if data is None: return idx, langkah = linear_search(data, target) if idx != -1: label_hasil.config(fg="darkgreen", text=f"✅ LINEAR: {target} ditemukan di indeks {idx} | {langkah} langkah") else: label_hasil.config(fg="darkred", text=f"❌ LINEAR: {target} tidak ditemukan | {langkah} langkah") def jalankan_binary(): data, target = parse_input() if data is None: return data_urut = sorted(data) label_data_urut.config(text=f"Data terurut: {data_urut}") idx, langkah = binary_search(data_urut, target) if idx != -1: label_hasil.config(fg="darkgreen", text=f"✅ BINARY: {target} ditemukan di indeks {idx} | {langkah} langkah") else: label_hasil.config(fg="darkred", text=f"❌ BINARY: {target} tidak ditemukan | {langkah} langkah") # ── Bangun jendela ── window = tk.Tk() window.title("Aplikasi Pencarian Data") window.geometry("500x260") window.resizable(False, False) tk.Label(window, text="Data (pisah koma):").pack(pady=(12,2)) entry_data = tk.Entry(window, width=50) entry_data.insert(0, "42, 8, 91, 15, 37, 26, 55, 73") entry_data.pack() tk.Label(window, text="Angka yang dicari:").pack(pady=(8,2)) entry_target = tk.Entry(window, width=10) entry_target.insert(0, "37") entry_target.pack() frame_btn = tk.Frame(window) frame_btn.pack(pady=10) tk.Button(frame_btn, text="🔎 Linear Search", command=jalankan_linear, bg="#2E75B6", fg="white", padx=10).pack(side="left", padx=6) tk.Button(frame_btn, text="⚡ Binary Search", command=jalankan_binary, bg="#2E7D32", fg="white", padx=10).pack(side="left", padx=6) label_data_urut = tk.Label(window, text="Data terurut: (klik Binary Search dulu)", font=("Courier", 9), fg="gray") label_data_urut.pack() label_hasil = tk.Label(window, text="Hasil akan muncul di sini...", font=("Segoe UI", 11, "bold")) label_hasil.pack(pady=8) window.mainloop()

💡 Petunjuk ▼

Gunakan fungsi linear_search(data, target) dan binary_search(data, target) yang sudah kita pelajari — tinggal disalin dan dipakai ulang. Untuk Binary Search, jangan lupa gunakan sorted(nim_list) dulu sebelum mencari. Untuk menampilkan perbandingan, cukup cetak jumlah langkah keduanya berdampingan.

✅ Contoh Kunci Jawaban ▼
PYTHON — cari_nim.py
# cari_nim.py def linear_search(data, target): for i in range(len(data)): if data[i] == target: return i, i + 1 return -1, len(data) def binary_search(data, target): low, high, langkah = 0, len(data) - 1, 0 while low <= high: langkah += 1 mid = (low + high) // 2 if data[mid] == target: return mid, langkah elif data[mid] < target: low = mid + 1 else: high = mid - 1 return -1, langkah nim_list = [2023045, 2023012, 2023078, 2023031, 2023056, 2023099, 2023023, 2023067] nim_urut = sorted(nim_list) nim_cari = int(input("Masukkan NIM yang dicari: ")) # Linear Search idx_l, langkah_l = linear_search(nim_list, nim_cari) # Binary Search idx_b, langkah_b = binary_search(nim_urut, nim_cari) print("\n=== HASIL PENCARIAN NIM ===") if idx_l != -1: print(f"Linear : ✅ ditemukan di indeks {idx_l} | {langkah_l} langkah") else: print(f"Linear : ❌ tidak ditemukan | {langkah_l} langkah") if idx_b != -1: print(f"Binary : ✅ ditemukan di indeks {idx_b} (data terurut) | {langkah_b} langkah") else: print(f"Binary : ❌ tidak ditemukan | {langkah_b} langkah") hemat = langkah_l - langkah_b print(f"\nBinary Search lebih hemat {hemat} langkah dibanding Linear Search.")
