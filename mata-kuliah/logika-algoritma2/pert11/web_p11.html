Apa itu File I/O?
Input/Output ke file di penyimpanan komputer

Selama ini data di program disimpan di memori (RAM) — ketika program ditutup, data hilang. Dengan File I/O, kita bisa menyimpan data ke hard disk sehingga bisa dibaca kembali kapanpun.

Mode Pembukaan File
Parameter kedua di fungsi open()
ModeNamaKeteranganFile Ada?File Tidak Ada?
"r" Read Hanya membaca isi file ✅ Dibuka ❌ Error
"w" Write Menulis ke file. Isi lama dihapus! ✅ Ditimpa ✅ Dibuat baru
"a" Append Menambah ke akhir file tanpa menghapus isi lama ✅ Ditambah ✅ Dibuat baru
"x" Create Membuat file baru saja ❌ Error ✅ Dibuat baru
"r+" Read+Write Baca sekaligus tulis ✅ Dibuka ❌ Error
⚠️
Mode "w" akan menghapus seluruh isi file jika file sudah ada! Gunakan "a" jika ingin menambahkan data tanpa menghapus yang lama.

1. Menulis File dengan open() mode "w" ▼

Gunakan with open(...) as f: — cara terbaik karena file otomatis tertutup setelah blok selesai, meski terjadi error.

PYTHON
# Cara 1: with statement (DISARANKAN) with open("catatan.txt", "w") as f: f.write("Halo, ini baris pertama!\n") f.write("Ini baris kedua.\n") f.write("Pertemuan 11 — File I/O\n") print("File berhasil ditulis!") # Cara 2: manual open/close (kurang aman) f = open("catatan.txt", "w") f.write("Contoh lain\n") f.close() # wajib ditutup manual!
✅
\n adalah karakter newline (baris baru). Tanpa \n, semua teks akan bersambung dalam satu baris.
2. Membaca File dengan mode "r" ▼

Ada 3 cara membaca file. Pilih sesuai kebutuhan.

PYTHON
# read() — baca semua isi file sekaligus with open("catatan.txt", "r") as f: isi = f.read() print(isi) # readline() — baca satu baris saja with open("catatan.txt", "r") as f: baris1 = f.readline() print("Baris 1:", baris1.strip()) # readlines() — baca semua baris ke dalam LIST with open("catatan.txt", "r") as f: semua = f.readlines() for i, baris in enumerate(semua): print(f"Baris {i+1}: {baris.strip()}")
3. Menambah Data dengan mode "a" (Append) ▼
⚠️
Mode "a" menambahkan data di akhir file tanpa menghapus isi yang sudah ada. Ini yang kamu butuhkan untuk membuat log atau catatan bertambah.
PYTHON
# Tambah baris baru ke file yang sudah ada with open("log.txt", "a") as f: f.write("[2025-01-15] User login: Budi\n") f.write("[2025-01-15] User logout: Budi\n") print("Log ditambahkan!") # Baca untuk cek hasilnya with open("log.txt", "r") as f: print(f.read())
4. Cek Keberadaan File dengan os.path ▼
PYTHON
import os # Cek apakah file ada if os.path.exists("catatan.txt"): print("File ditemukan!") with open("catatan.txt", "r") as f: print(f.read()) else: print("File tidak ditemukan!") # Hapus file if os.path.exists("temp.txt"): os.remove("temp.txt") print("File dihapus.") # Lihat semua file di folder saat ini print(os.listdir("."))
5. Penanganan Error dengan try-except ▼

Selalu antisipasi kemungkinan file tidak ada atau tidak bisa dibuka menggunakan try-except.

PYTHON
try: with open("data.txt", "r") as f: isi = f.read() print(isi) except FileNotFoundError: print("❌ Error: File 'data.txt' tidak ditemukan!") except PermissionError: print("❌ Error: Tidak punya izin buka file!") except Exception as e: print(f"❌ Error tidak terduga: {e}") else: print("✅ File berhasil dibaca.") finally: print("Proses selesai.") # selalu dijalankan
6. writelines() — Tulis dari List ▼
PYTHON
# writelines() menulis list of string ke file mahasiswa = [ "Andi\n", "Budi\n", "Citra\n", "Dina\n" ] with open("mahasiswa.txt", "w") as f: f.writelines(mahasiswa) print("Data mahasiswa tersimpan!") # Baca kembali with open("mahasiswa.txt", "r") as f: daftar = f.readlines() print(f"Total mahasiswa: {len(daftar)}") for nama in daftar: print(f" - {nama.strip()}")

📝 Aplikasi 1: Notepad Sederhana (Tkinter + File I/O) ▼

Aplikasi notepad dengan tombol Simpan dan Buka file. Ini adalah dasar dari hampir semua aplikasi desktop.

PYTHON — JALANKAN DI COLAB / PYTHON LOKAL
import tkinter as tk from tkinter import messagebox, filedialog def simpan_file(): # Ambil teks dari widget Text isi = text_area.get("1.0", tk.END) nama_file = entry_nama.get() if not nama_file: messagebox.showerror("Error", "Nama file tidak boleh kosong!") return try: with open(nama_file, "w") as f: f.write(isi) messagebox.showinfo("Sukses", f"File '{nama_file}' berhasil disimpan!") except Exception as e: messagebox.showerror("Error", f"Gagal simpan: {e}") def buka_file(): nama_file = entry_nama.get() if not nama_file: messagebox.showerror("Error", "Masukkan nama file yang ingin dibuka!") return try: with open(nama_file, "r") as f: isi = f.read() text_area.delete("1.0", tk.END) text_area.insert("1.0", isi) except FileNotFoundError: messagebox.showerror("Error", f"File '{nama_file}' tidak ditemukan!") def hapus_teks(): text_area.delete("1.0", tk.END) # ── Setup Window ────────────────────────────── root = tk.Tk() root.title("Notepad Sederhana — File I/O") root.geometry("600x450") root.configure(bg="#f0f4f8") # ── Baris Nama File ─────────────────────────── frame_top = tk.Frame(root, bg="#f0f4f8", pady=8) frame_top.pack(fill="x", padx=10) tk.Label(frame_top, text="Nama File:", bg="#f0f4f8").pack(side="left") entry_nama = tk.Entry(frame_top, width=30, font=("Courier", 12)) entry_nama.pack(side="left", padx=8) entry_nama.insert(0, "catatan.txt") # ── Tombol ──────────────────────────────────── frame_btn = tk.Frame(root, bg="#f0f4f8") frame_btn.pack(fill="x", padx=10, pady=4) tk.Button(frame_btn, text="💾 Simpan", command=simpan_file, bg="#16A34A", fg="white", padx=12).pack(side="left", padx=4) tk.Button(frame_btn, text="📂 Buka", command=buka_file, bg="#2E75B6", fg="white", padx=12).pack(side="left", padx=4) tk.Button(frame_btn, text="🗑️ Bersihkan", command=hapus_teks, bg="#EF4444", fg="white", padx=12).pack(side="left", padx=4) # ── Area Teks ───────────────────────────────── text_area = tk.Text(root, font=("Courier", 12), wrap="word", padx=10, pady=10) text_area.pack(expand=True, fill="both", padx=10, pady=8) root.mainloop()
📒 Aplikasi 2: Buku Catatan Nama Mahasiswa ▼

Aplikasi untuk menambah, menampilkan, dan menghapus daftar nama dari file teks. Menggabungkan Listbox Tkinter dengan operasi append dan read file.

PYTHON — JALANKAN DI COLAB / PYTHON LOKAL
import tkinter as tk from tkinter import messagebox FILE_NAMA = "daftar_mahasiswa.txt" def muat_data(): "Muat data dari file ke listbox" listbox.delete(0, tk.END) try: with open(FILE_NAMA, "r") as f: for nama in f.readlines(): listbox.insert(tk.END, nama.strip()) except FileNotFoundError: pass # file belum ada, tidak apa-apa def tambah_nama(): nama = entry.get().strip() if not nama: messagebox.showwarning("Peringatan", "Nama tidak boleh kosong!") return with open(FILE_NAMA, "a") as f: f.write(nama + "\n") entry.delete(0, tk.END) muat_data() lbl_status.config(text=f"✅ '{nama}' ditambahkan!") def hapus_terpilih(): sel = listbox.curselection() if not sel: messagebox.showwarning("Peringatan", "Pilih nama yang ingin dihapus!") return nama_hapus = listbox.get(sel[0]) with open(FILE_NAMA, "r") as f: semua = f.readlines() with open(FILE_NAMA, "w") as f: for baris in semua: if baris.strip() != nama_hapus: f.write(baris) muat_data() lbl_status.config(text=f"🗑️ '{nama_hapus}' dihapus!") root = tk.Tk() root.title("Daftar Mahasiswa") root.geometry("400x500") tk.Label(root, text="📒 Buku Mahasiswa", font=("Arial",14,"bold")).pack(pady=10) frame = tk.Frame(root) frame.pack(padx=10, fill="x") entry = tk.Entry(frame, font=("Arial",12), width=25) entry.pack(side="left", padx=4) tk.Button(frame, text="+ Tambah", command=tambah_nama, bg="#16A34A", fg="white").pack(side="left") listbox = tk.Listbox(root, font=("Arial",12), height=15, selectmode=tk.SINGLE) listbox.pack(padx=10, pady=10, fill="both", expand=True) tk.Button(root, text="🗑️ Hapus Terpilih", command=hapus_terpilih, bg="#EF4444", fg="white").pack(pady=4) tk.Button(root, text="🔄 Refresh", command=muat_data).pack(pady=2) lbl_status = tk.Label(root, text="Siap", fg="gray") lbl_status.pack() muat_data() root.mainloop()

Pola Umum Integrasi UI + File
Gunakan pola ini untuk semua proyek
📥 Tombol "Simpan"
Ambil data dari widget → buka file mode "w" atau "a" → tulis → tutup → tampilkan pesan sukses
📤 Tombol "Buka/Load"
Buka file mode "r" → baca → masukkan ke widget (Text/Listbox/Label) → tampilkan
🗑️ Tombol "Hapus"
Baca semua → filter yang tidak dihapus → tulis ulang dengan mode "w"
