03 · Konsep Utama

📦Array (List) di Python

🧠 Apa itu List/Array?

Di Python, array disebut list. List adalah kumpulan data yang disimpan dalam satu variabel. Datanya terurut, bisa diubah, dan bisa berisi tipe data apa saja.

PYTHON · Membuat List 
# Cara membuat list di Python
# Gunakan kurung siku [ ] dan pisahkan dengan koma

nilai = [80, 90, 75, 85]

# List juga bisa berisi teks (string)
nama = ["Budi", "Siti", "Andi"]

# List bisa berisi campuran tipe data
data = ["Budi", 20, 85.5]

# Tampilkan semua isi list
print(nilai)   # Output: [80, 90, 75, 85]

Coba kita visualisasikan seperti ini — setiap data punya nomor urut yang disebut index:

nilai = [80, 90, 75, 85]

80index [0]
90index [1]
75index [2]
85index [3]
💡

Index dimulai dari 0, bukan 1! Jadi data pertama ada di index 0, kedua di index 1, dan seterusnya. Ini penting banget!

🔢 Berapa panjang list kita?

PYTHON 
nilai = [80, 90, 75, 85]

# len() = length = panjang/jumlah elemen
print(len(nilai))   # Output: 4
04 · Mengambil Data

🎯Akses Data dengan Index

Kalau datanya banyak, gimana cara kita ambil satu data tertentu? Gunakan index!

PYTHON · Akses dengan Index 
nilai = [80, 90, 75, 85]

print(nilai[0])   # Output: 80 ← data pertama
print(nilai[1])   # Output: 90 ← data kedua
print(nilai[2])   # Output: 75 ← data ketiga
print(nilai[3])   # Output: 85 ← data keempat

# Index negatif = dari belakang!
print(nilai[-1])  # Output: 85 ← data terakhir

Klik salah satu untuk melihat cara aksesnya:

90[1]
75[2]
85[3]

👆 Klik cell di atas untuk melihat cara mengakses nilainya

⚠️

Hati-hati! Kalau kita akses index yang tidak ada (misal nilai[10] padahal cuma ada 4 data), Python akan kasih error: IndexError: list index out of range. Pastikan index tidak melebihi panjang list!

05 · Perulangan

🔄Traversal — Keliling Semua Data

Kalau datanya banyak, kita tidak mau print satu-satu kan? Gunakan for loop untuk keliling semua elemen list!

PYTHON · For Loop pada List 
nilai = [80, 90, 75, 85]

# Cara 1: Loop langsung — "n" berisi nilai satu per satu
for n in nilai:
    print(n)
# Output: 80, 90, 75, 85 (masing-masing baris sendiri)

# Cara 2: Pakai index (enumerate) — tahu posisinya juga
for i, n in enumerate(nilai):
    print(f"Index {i}: {n}")
# Output: Index 0: 80, Index 1: 90, dst.

# Cara 3: Pakai range — klasik seperti C/Java
for i in range(len(nilai)):
    print(nilai[i])

↑

↑

↑
85[3]
i=3
💡

Logika for loop: Setiap iterasi (putaran), variabel n berisi satu elemen dari list. Loop akan terus jalan sampai semua elemen habis dikunjungi. Python yang atur semuanya — kita tidak perlu mengelola index secara manual!

06 · Operasi CRUD

⚙️Operasi pada Array

Ada 3 operasi dasar yang wajib kita kuasai: Tambah (Insert), Hapus (Delete), dan Ubah (Update).

➕ INSERT — Tambah Data .append()

Untuk menambahkan data di akhir list, gunakan .append(). Namanya "append" yang artinya menambahkan ke ujung.

PYTHON · Insert / Append 
nilai = [80, 90, 75, 85]

# Tambah di akhir
nilai.append(100)
print(nilai)  # [80, 90, 75, 85, 100]

# Tambah di posisi tertentu — .insert(index, nilai)
nilai.insert(1, 95)
print(nilai)  # [80, 95, 90, 75, 85, 100]

🗑️ DELETE — Hapus Data .remove()

Untuk menghapus data berdasarkan nilainya, gunakan .remove(). Kalau mau hapus berdasarkan index, gunakan .pop() atau del.

PYTHON · Delete / Remove 
nilai = [80, 90, 75, 85]

# Hapus berdasarkan nilai (angka 75 dihapus)
nilai.remove(75)
print(nilai)  # [80, 90, 85]

# Hapus berdasarkan index — .pop(index)
nilai.pop(0)   # Hapus index ke-0 (angka 80)
print(nilai)  # [90, 85]

# Hapus dengan del
del nilai[0]
print(nilai)  # [85]

Untuk mengubah nilai di index tertentu, langsung akses indexnya dan beri nilai baru!

07 · Dimensi Dua

🗂️Array 2 Dimensi (2D)

🧠 Apa itu Array 2D?

Array 2D adalah list di dalam list — seperti tabel atau spreadsheet. Baris adalah list luar, kolom adalah list dalam.

PYTHON · Array 2D 
# Array 2D = list di dalam list
# Bayangkan seperti tabel dengan baris & kolom

nilai = [
    [80, 90],   # baris 0: kolom 0=80, kolom 1=90
    [75, 85],   # baris 1: kolom 0=75, kolom 1=85
    [92, 78]    # baris 2: kolom 0=92, kolom 1=78
]

print(nilai)
# Output: [[80, 90], [75, 85], [92, 78]]

📊 Visualisasi sebagai tabel:

Kolom [0] Kolom [1]
Baris [0] 80 90
Baris [1] 75 85
Baris [2] 92 78

nilai[baris][kolom]

nilai[0][0] = 80 nilai[0][1] = 90 nilai[1][0] = 75 nilai[1][1] = 85 nilai[2][0] = 92 nilai[2][1] = 78

👆 Klik salah satu untuk melihat penjelasannya

🔁 Nested Loop — Loop di dalam Loop

Untuk keliling semua elemen array 2D, kita butuh 2 loop: loop luar untuk baris, loop dalam untuk kolom.

PYTHON · Nested Loop (2D) 
nilai = [[80, 90], [75, 85], [92, 78]]

# Loop luar → satu "baris" per iterasi
for baris in nilai:
        # Loop dalam → satu "nilai" per iterasi
        for kolom in baris:
                print(kolom, end=" ")
        print()  # pindah baris setelah satu baris selesai

# Output:
# 80 90
# 75 85
# 92 78

Alur logika nested loop:

  • 1
    Loop luar mulai: baris = [80, 90]

    Loop pertama ambil baris pertama: list [80, 90]

  • 2
    Loop dalam: kolom = 80, lalu 90

    Loop dalam keliling isi baris: print 80, lalu print 90

  • 3
    Pindah baris: baris = [75, 85]

    Loop luar lanjut ke baris berikutnya, ulangi proses yang sama

  • 4
    Selesai saat semua baris habis

    Total iterasi = jumlah baris × jumlah kolom = 3 × 2 = 6

08 · Studi Kasus Lengkap

💼Data Nilai Mahasiswa

📋 Deskripsi Kasus

Kita punya data nilai 3 mahasiswa. Kita ingin: tampilkan semua data, hitung rata-rata nilai, dan cari nilai tertinggi.

PYTHON · Studi Kasus Lengkap 
# ============================
# DATA NILAI MAHASISWA
# Format: [nama, nilai]
# ============================

data = [
    ["Budi",  80],
    ["Siti",  90],
    ["Andi",  75],
    ["Dewi",  88],
    ["Reza",  95]
]

# ============================
# LANGKAH 1: Tampilkan semua data
# ============================
print("=== DATA NILAI MAHASISWA ===")
print(f"{'Nama':10} | Nilai")
print("-" * 20)

for mahasiswa in data:
    nama  = mahasiswa[0]   # kolom 0 = nama
    nilai = mahasiswa[1]   # kolom 1 = nilai
        print(f"{nama:10} | {nilai}")

# ============================
# LANGKAH 2: Hitung total & rata-rata
# ============================
total = 0

for mahasiswa in data:
        total = total + mahasiswa[1]   # akumulasi nilai

rata_rata = total / len(data)
print(f"\nTotal  : {total}")
print(f"Rata²  : {rata_rata:.1f}")

# ============================
# LANGKAH 3: Cari nilai tertinggi
# ============================
nilai_max = data[0][1]   # anggap nilai pertama sebagai max awal
nama_max  = data[0][0]

for mahasiswa in data:
        if mahasiswa[1] > nilai_max:
                nilai_max = mahasiswa[1]
                nama_max  = mahasiswa[0]

print(f"Nilai tertinggi: {nama_max} ({nilai_max})")

📖 Penjelasan langkah demi langkah:

  • 1
    Mendefinisikan data 2D

    data adalah list yang berisi list. Setiap elemen dalam data adalah list [nama, nilai]. Jadi data[0] → ["Budi", 80], dan data[0][0] → "Budi"

  • 2
    Loop untuk tampilkan data

    Setiap iterasi, variabel mahasiswa berisi satu baris data (mis. ["Budi", 80]). Kita ambil index 0 untuk nama dan index 1 untuk nilai.

  • 3
    Hitung rata-rata dengan akumulasi

    Variabel total dimulai dari 0, lalu di setiap iterasi kita tambahkan nilai mahasiswa. Setelah loop selesai, bagi total dengan jumlah data (len(data)).

  • 4
    Cari nilai tertinggi

    Trik klasik! Anggap dulu data pertama sebagai maksimum. Lalu bandingkan satu-satu dengan if. Jika ketemu yang lebih besar, update variabel nilai_max.

🔴 Latihan 3 — Array 2D Nama & Nilai

Buat array 2D berisi data 4 mahasiswa dengan format [nama, nilai_tugas, nilai_uts]. Tampilkan semua data dan hitung rata-rata per mahasiswa (nilai_tugas + nilai_uts) / 2.

Budi : Tugas=80, UTS=85, Rata²=82.5
Siti : Tugas=90, UTS=92, Rata²=91.0
...
JAWABAN · Latihan 3 
# Array 2D: [nama, nilai_tugas, nilai_uts]
mahasiswa = [
    ["Budi",  80, 85],
    ["Siti",  90, 92],
    ["Andi",  75, 70],
    ["Dewi",  88, 95]
]

print(f"{'Nama':8} | Tugas | UTS | Rata²")
print("-" * 32)

for m in mahasiswa:
        nama  = m[0]
        tugas = m[1]
        uts   = m[2]
        rata  = (tugas + uts) / 2
        print(f"{nama:8} | {tugas:5} | {uts:3} | {rata:.1f}")
